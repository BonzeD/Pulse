# Pulse 1.0.0 — Cosmic Dawn

## Что изменилось

- «Чёрный океан»: другая панорама — ESO/S. Brunier, GigaGalaxy Zoom. Локальный JPEG 6000 × 3000 из исходного TIFF, сферическая проекция, ориентация и экспозиция в шейдере. Небо участвует в отражениях воды; Луна и мягкий ореол сохранены.
- «Орбитальная станция»: новая оригинальная модульная модель — кольцо из 64 сегментов, силовые фермы, центральный узел, герметичные модули, радиатор, антенна, солнечные панели с сеткой ячеек.
- Металлы с normal/roughness-картами, физический материал солнечных панелей, прямой солнечный свет, подсветка от Земли и реальные теневые карты. Повторяемые детали объединены в InstancedMesh.
- Земля: локальные карты NASA Blue Marble / Black Marble 8192 × 4096, отдельная облачная оболочка, ночные огни, атмосферный ободок, солнечный блик океана.
- Реальные бас, середина, высокие частоты и транзиенты управляют 64 световыми сегментами, огнями и реактором; транспорт и звуковой тракт не изменены.
- Подписи источников в сцене, справке, CREDITS.md и NOTICE.md. Интернет при запуске сцены не нужен.

## Проверки

- `npm test`: 171/171.
- `tests/immersion-rework-ui.cjs`: 10 UI-сценариев — все три мира, реальная разница аудиореакции, обработчики штатного плеера, hit targets на 1366/980/390 px, справка, пауза, выход, Clean UI, reduced motion.
- `CHROMIUM_PATH=/path/to/chromium node tests/cosmic-preview.cjs`: полноразмерные кадры океана и станции, загрузка текстур, отсутствие ошибок JavaScript/шейдеров/WebGL.
- `tests/immersion-audio-ui.cjs`: настоящий WebAudio PCM → readSpectrum → директор → свет станции; реакция на амплитуду и паузу.
- UI-тесты ожидают измеренного установившегося состояния аудиоогибающей, а не фиксированной задержки в миллисекундах: программный GPU может отрисовывать кадры медленнее реального устройства.

## Сборка

Версия намеренно сохранена 1.0.0. `npm ci`, затем `npm run build:graphics` и `npm run dist`. При ограниченной памяти используйте `ELECTRON_BUILDER_COMPRESSION_LEVEL=5 npm run dist`. Для `build:media` требуется .NET 8 SDK; подробности в native/media-bridge. Медиамост выпуска переиспользован из предыдущей сборки без изменений исходного Program.cs.

EXE не подписаны. На настоящем Windows, конкретной видеокарте, DPI и в длительном воспроизведении сборка здесь не проверялась. Автоматические проверки используют Chromium в Linux с программным WebGL; это не измерение FPS на пользовательском GPU.

Все ссылки на источники, лицензии и изменения материалов: `renderer/immersion-assets/CREDITS.md`. Модель станции — вымышленная, созданная для Pulse; карты NASA не означают одобрения NASA.
