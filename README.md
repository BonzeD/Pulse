# Pulse

**1.0.2 · Windows x64 · GPL-3.0-or-later**

Музыкальный клиент с каталогами YouTube Music, Apple Music, Spotify и Audius, текстами песен, визуализациями, MineRadio, офлайн-загрузками и мини-виджетом.

> Независимый проект, не официальный клиент перечисленных сервисов. Доступность каталогов, авторизации и воспроизведения зависит от сервисов, региона и прав на контент. Pulse не обещает обход DRM или платной подписки.

## Audius

- Четвёртая кнопка платформы (нота) открывает публичный каталог Audius без входа. Поиск: треки, исполнители и плейлисты; главная: популярные треки и плейлисты.
- Аудио из Audius играет напрямую. Лайки и локальные плейлисты хранятся в Pulse, не в аккаунте Audius. Скачивание Audius отключено.
- **Настройки → Клиент → Audius → Источник звука**: «Текущий источник» (по умолчанию), «Автоматически», «Предпочитать Audius». Автоматический режим использует только заранее проверенное совпадение; «Предпочитать» допускает короткий ограниченный поиск.
- Кнопка источника над панелью плеера показывает фактический источник, открывает запись в Audius, позволяет вручную выбрать другую запись или сбросить соответствие. Своя синхронизация текста блокирует альтернативную запись.
- Ограничения и проверенные сценарии: [AUDIUS-1.0.2](docs/verification/AUDIUS-1.0.2.md).

## Преимущества

- **Музыка из разных сервисов в одном приложении** — не нужно постоянно переключаться между отдельными клиентами.
- **Удобный мини-виджет** — управление воспроизведением остаётся под рукой и не занимает много места.
- **Офлайн-возможности** — поддержка локальной медиатеки и загрузок для доступного без сети контента.
- **Гибкое оформление** — визуализации и параметры интерфейса позволяют настроить Pulse под себя.
- **Открытый исходный код** — проект можно изучать, проверять и развивать вместе с сообществом.

## Особенности

- Каталоги **YouTube Music, Apple Music и Spotify** в едином интерфейсе.
- Тексты песен и визуализации во время воспроизведения.
- **MineRadio** и локальная медиатека.
- Компактный перетаскиваемый мини-виджет.
- Интеграция с системным управлением мультимедиа Windows через **SMTC**.
- Обычная и portable-сборки для Windows x64.
- Русская и английская локализации интерфейса.

## Разработка

Нужен **Node.js 24**. Команды выполняются **из корня репозитория**:

```sh
npm ci
npm test
npm start
```

Корневая установка автоматически выполняет `npm ci` в `app/`; зависимости находятся в `app/node_modules/`. Корневые команды перенаправляются в приложение. Можно также работать напрямую из `app/`.

Для Windows SMTC-медиамоста дополнительно нужен **.NET SDK 8**:

```sh
npm run build:media
```

.NET runtime конечному пользователю отдельно не требуется: медиамост self-contained. Нативную интеграцию необходимо проверять на Windows. [SMTC / Windhawk](docs/windows-media-session.md).

## Собрать Windows x64

Полная сборка предназначена для **Linux / WSL / GitHub Actions**. Помимо Node.js и .NET SDK 8, для исходного установщика нужны Chromium, Python 3 и Pillow. Путь к Chromium можно передать через `CHROMIUM`.

```sh
npm run dist
```

Результаты:

```text
app/dist/Pulse-1.0.2-portable.exe
app/dist/Pulse-Setup-1.0.2.exe
```

В GitHub Actions доступен workflow **Build Windows artifacts**. Он собирает EXE, но не публикует Release и не проверяет нативное поведение Windows автоматически.
