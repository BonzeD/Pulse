# Pulse

**1.0.0 · Windows x64 · GPL-3.0-or-later**

Музыкальный клиент с каталогами YouTube Music, Apple Music и Spotify, текстами песен, визуализациями, MineRadio, офлайн-загрузками и мини-виджетом.

> Независимый проект, не официальный клиент перечисленных сервисов. Доступность каталогов, авторизации и воспроизведения зависит от сервисов, региона и прав на контент. Pulse не обещает обход DRM или платной подписки.

## Скачать

Откройте **Releases** этого репозитория:

- `Pulse-Setup-1.0.0.exe` — установщик.
- `Pulse-1.0.0-portable.exe` — portable-версия.

Сборки не подписаны сертификатом. Перед обновлением завершите Pulse через «Выход» в трее и сохраните резервную копию пользовательской библиотеки. Не отключайте защиту Windows ради запуска.

## Разработка

Нужен **Node.js 24**. Команды выполняются **из корня репозитория**:

```sh
npm ci
npm test
npm start
```

Корневая установка автоматически выполняет `npm ci` в `app/`; зависимости находятся в `app/node_modules/`. Корневые команды перенаправляются в приложение. Можно также работать напрямую из `app/`.

Для Windows SMTC-медиамоста дополнительно нужен **.NET SDK 8**:

```sh
npm run build:media
```

.NET runtime конечному пользователю отдельно не требуется: медиамост self-contained. Нативную интеграцию необходимо проверять на Windows. [SMTC / Windhawk](docs/windows-media-session.md).

## Собрать Windows x64

Полная сборка предназначена для **Linux / WSL / GitHub Actions**. Помимо Node.js и .NET SDK 8, для исходного установщика нужны Chromium, Python 3 и Pillow. Путь к Chromium можно передать через `CHROMIUM`.

```sh
npm run dist
```

Результаты:

```text
app/dist/Pulse-1.0.0-portable.exe
app/dist/Pulse-Setup-1.0.0.exe
```

В GitHub Actions доступен workflow **Build Windows artifacts**. Он собирает EXE, но не публикует Release и не проверяет нативное поведение Windows автоматически.
