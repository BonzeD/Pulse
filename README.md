# Pulse

**1.0.3 · Windows x64 · GPL-3.0-or-later**

Музыкальный клиент с каталогами YouTube Music, Apple Music, Spotify и Audius, текстами песен, визуализациями, MineRadio, офлайн-загрузками и мини-виджетом.

> Независимый проект, не официальный клиент перечисленных сервисов. Доступность каталогов, авторизации и воспроизведения зависит от сервисов, региона и прав на контент. Pulse не обещает обход DRM или платной подписки.

## Воспроизведение в 1.0.3

Онлайн-треки сначала открываются во встроенном YouTube. При ошибке или отсутствии старта Pulse пробует резервный поток; локальные и скачанные файлы остаются в файловом плеере. Пауза и позиция сохраняются при переключении источника. Доступность каждого ролика не гарантируется.

Звук встроенного YouTube не проходит через обычные аудиодеки Pulse: EQ, DJ-сведение и эффекты этой цепочки для него недоступны; полный AutoSync-анализ онлайн-трека не запускается. Скачанные файлы и прямое воспроизведение сохраняют свой прежний аудиотракт.

## Audius

- Четвёртая кнопка платформы (нота) открывает публичный каталог Audius без входа. Поиск: треки, исполнители и плейлисты; главная: популярные треки и плейлисты.
- Аудио из Audius играет напрямую. Лайки и локальные плейлисты хранятся в Pulse, не в аккаунте Audius. Скачивание Audius отключено.
- **Настройки → Клиент → Audius → Источник звука**: «Текущий источник» (по умолчанию), «Автоматически», «Предпочитать Audius». Автоматический режим использует только заранее проверенное совпадение; «Предпочитать» допускает короткий ограниченный поиск.
- В **Настройки → Клиент → Audius → Источник текущего трека** можно посмотреть фактический источник, открыть запись в Audius, вручную выбрать другую запись или сбросить соответствие. Своя синхронизация текста блокирует альтернативную запись.
- Ограничения и проверенные сценарии: [AUDIUS-1.0.2](Logs/1.0.2.md).

## Преимущества

- **Музыка из разных сервисов в одном приложении** — не нужно постоянно переключаться между отдельными клиентами.
- **Удобный мини-виджет** — управление воспроизведением остаётся под рукой и не занимает много места.
- **Офлайн-возможности** — поддержка локальной медиатеки и загрузок для доступного без сети контента.
- **Гибкое оформление** — визуализации и параметры интерфейса позволяют настроить Pulse под себя.
- **Открытый исходный код** — проект можно изучать, проверять и развивать вместе с сообществом.

## Особенности

- Каталоги **YouTube Music, Apple Music и Spotify** в едином интерфейсе.
- Тексты песен и визуализации во время воспроизведения.
- **MineRadio** и локальная медиатека.
- Компактный перетаскиваемый мини-виджет.
- Интеграция с системным управлением мультимедиа Windows через **SMTC**.
- Обычная и portable-сборки для Windows x64.
- Русская и английская локализации интерфейса.

## Разработка

Нужен **Node.js 24**. Команды выполняются **из корня репозитория**:

```sh
npm ci
npm test
npm start
```

Корневая установка автоматически выполняет `npm ci` в `app/`; зависимости находятся в `app/node_modules/`. Корневые команды перенаправляются в приложение. Можно также работать напрямую из `app/`.

Для Windows SMTC-медиамоста дополнительно нужен **.NET SDK 8**:

```sh
npm run build:media
```

.NET runtime конечному пользователю отдельно не требуется: медиамост self-contained. Нативную интеграцию необходимо проверять на Windows. [SMTC / Windhawk](.maintenance/ai/oldlogs/windows-media-session.md).

## Собрать только portable

После `npm ci` установите .NET SDK 8 и выполните из корня:

```sh
npm run build:media
cd app
./node_modules/.bin/electron-builder --win portable --x64 --publish never
```

Результат: `app/dist/Pulse-1.0.3-portable.exe`. Установщик эта команда не создаёт; цифровая подпись не настроена.

## Полная сборка Windows x64

Полная сборка предназначена для **Linux / WSL / GitHub Actions**. Помимо Node.js и .NET SDK 8, для исходного установщика нужны Chromium, Python 3 и Pillow. Путь к Chromium можно передать через `CHROMIUM`.

```sh
npm run dist
```

Результаты:

```text
app/dist/Pulse-1.0.3-portable.exe
app/dist/Pulse-Setup-1.0.3.exe
```

В GitHub Actions доступен workflow **Build Windows artifacts**. Он собирает EXE, но не публикует Release и не проверяет нативное поведение Windows автоматически.

## Атлас и setup (1.0.3)

**Атлас** начинается с пустой карты. Нажмите «Добавить звезду», чтобы поместить на неё локальный плейлист Pulse, плейлист текущего сервиса или собственный список песен. Локальный плейлист остаётся связан с библиотекой; у сервисного сохраняется снимок состава на момент добавления; для одной песни открывается её карточка. Локальные файлы сначала импортируются в библиотеку Pulse. Для длинного списка выбор песен ограничен первыми 1 000 доступных записей.

Выберите две или более свободных звезды и создайте именованное созвездие. В «Редакторе созвездия» выбирайте инструмент «Звёзды» для перемещения отдельной звезды или «Перемещение», чтобы перетащить всю группу. Крутите диск или ползунок для свободного поворота, а в режиме «Связи» выбирайте две звезды, чтобы соединить или разъединить их. Можно добавлять и убирать участников, отменять и повторять изменения. Связи и участники не удаляются, если это разрывает группу. Стрелки на выбранной звезде двигают её; с Shift — быстрее. Удаление созвездия или звезды с карты не удаляет музыку из библиотеки.

Карта хранится на устройстве в библиотеке Pulse. Музыка запускается через существующую очередь: играющая звезда красная, а соседние по созвездию пульсируют слабее. Пульсация — визуальная анимация, не измерение звука или ритма. Для онлайн-треков по-прежнему может понадобиться интернет; локальные и скачанные треки используют существующий файловый плеер. Интерфейс Атласа доступен на русском и английском, для других языков используется английский. Учитывается настройка уменьшения движения.

Сборка **Windows x64 setup и portable** не имеет цифровой подписи. Установка сохраняет профиль; удаление предлагает отдельный выбор данных. Реальная установка, звук и доступность сервисов требуют проверки на Windows.

Атлас представляет небо как сферу: перетаскивайте пустое пространство, чтобы оглядеться, или используйте стрелки при фокусе на карте. Из меню песни её можно добавить как отдельную звезду либо сразу соединить с созвездием. Настройки открываются поверх неба. Поддерживаются списки текущего сервиса, доступные в боковой панели; для загрузки состава нужен вход и подключение. Кнопка «Мои созвездия» помогает найти свои звёзды и группы. Панорама находится внутри трёхмерной сферы, а не представляет собой объёмную модель галактики. Старая карта версии 1 переносится в новый формат при первом открытии Атласа; её копия сохраняется в библиотеке. Если WebGL недоступен, используется запасной фон.


Рабочая область Атласа и вкладки «Визуал» подстраивается под показанную или скрытую панель плеера. На самой странице Атласа прокрутка отключена; длинные списки и настройки прокручиваются внутри своей панели.

Атлас v2: пустой чёрный космос, в котором каждый плейлист или подборка песен становится звездой (звезда с одной песней открывает страницу песни). Звёзды объединяются в именованные созвездия с настраиваемыми связями, положением, поворотом и размером; граф созвездия всегда связный. Рендер — Canvas 2D без WebGL и внешних текстур; воспроизведение идёт через обычный плеер Pulse. Старые данные Атласа мигрируются автоматически (копия сохраняется в lib.atlasCosmosLegacy).
