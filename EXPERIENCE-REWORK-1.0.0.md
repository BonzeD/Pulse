# Pulse 1.0.0 — удобство, красота и визуалы

Номер версии сохранён: **1.0.0**. Этот документ описывает текущую переработку; прежние IMMERSION/INSTALL-отчёты остаются историей.

## Что изменено

### «Погружение» теперь внутри «Только текст»
- Открой «Только текст» клавишей **T** и выбери **Погружение** в обычном переключателе стилей.
- Доступны только **Орбитальная станция** и **Чёрное море**. Долина и автоматическое переключение миров больше не предлагаются.
- Используется тот же `#lyStage`, тот же переключатель стилей и настоящий `#bar`. Больше нет отдельной навигации, модального экрана, собственной шапки, справки поверх сцены или переноса панели между DOM-контейнерами.
- Выбор мира и качества встроен в стандартную верхнюю панель. Сохраняются штатные скрытие интерфейса, закрепление панели, выход и остальные стили, включая MineRadio.
- Сценический режим не выводит слова поверх мира. Возврат к «Классике», «Кинетике» или «Столбику» возвращает обычный текст.
- Ошибки GPU/WebGL не останавливают музыку; на экране остаются понятное сообщение и обычный переключатель стилей.

### Реакции на курсор
- Карточки библиотеки, обложки, визуальные карточки и развёрнутая обложка получают мягкий локальный свет; обложка текстового режима — лёгкий наклон.
- Центр стандартных Canvas/GPU-визуалов мягко следует за курсором; орбита и море используют небольшое ограниченное смещение камеры.
- Частицы текстовой сцены слегка расходятся около курсора.
- Общая служба курсора объединяет события в один кадр, читает размеры только при смене объекта и не имеет собственного непрерывного цикла.
- Эффекты не перехватывают клики и отключаются при `prefers-reduced-motion`, запрете анимаций, скрытом окне и отсутствии точного указателя.

### Общая компактная панель
- В узком окне (до 600 px) основная и текстовая панели используют одну двухрядную компоновку.
- Обложка, название, лайк, предыдущий/пауза/следующий, очередь, звук и доступ к настройке вида/меню помещаются в окно. Важные кнопки больше не обрезаются справа.

### Установщик из предоставленного архива
- По последнему запросу возвращены `build/installer.nsi` и весь `build/installer-ui/` из `Pulse-1.0.0-source(2).zip`, без редизайна и перевода исходного интерфейса.
- Сохранены текущие обновления приложения, версии 1.0.0, исправленная проверка путей и актуальный манифест файлов текущего payload. Старые исходники приложения из архива не импортировались.
- Восстановлено исходное поведение установщика: русские экраны, анимации, завершение Pulse перед заменой файлов и прежние флажки удаления данных. При удалении нужно внимательно проверять выбранные опции.
- Минимальная адаптация сборочного shell-скрипта позволяет указать путь `MAKENSIS`; сам NSIS-скрипт и все ресурсы интерфейса совпадают с архивом.

### Производительность и совместимость
- Миры больше не пересоздаются при смене песни: обновляются аудиореакция и цвет обложки, без повторной компиляции геометрии/материалов.
- Сохранены профили качества, адаптивное понижение детализации, ограничение частоты кадров и остановка рендера скрытого окна.
- Не менялись сетевые сервисы, аудиодвижок, форматы библиотеки или содержимое пользовательских профилей. Новые настройки ограничены выбранным стилем, миром и качеством.
- Авторство и лицензии сцен сохранены в `NOTICE.md`, `renderer/immersion-assets/CREDITS.md` и разделе «О программе».

## Проверки

- `npm test`: **182 теста, 182 passed, 0 failed**. Проверки старого отдельного интерфейса заменены проверками нативной интеграции; добавлены тесты курсора.
- `npm run test:experience`: браузерный сценарий на Chromium со стабами desktop API: обе сцены, единственный транспорт, смена стиля, Esc, маленькое окно 390 × 844, восстановление после отключённого GPU и системное ограничение анимаций. Нет ошибок JavaScript.
- Визуально просмотрены скриншоты орбиты, моря, обычного текстового режима, узкого окна, ошибки GPU и сцен приложения; графика установщика теперь берётся из архива.
- Three.js bundle пересобран из исходных `.mjs`.
- NSIS-скрипт и UI взяты из предоставленного архива. Setup упаковывает текущее полноценное приложение, а не тестовую заглушку; проверка сборки и упаковки не заменяет реальную установку в Windows.
- Старый `tests/ui.cjs` сохранён без изменений. Его общий smoke-test не является зелёным: он считает штатную вынесенную кнопку `btnBarHide` выходом за границы панели; при временном обходе этой проверки также проявляется устаревшее ожидание прокрутки страницы настроек. Эти старые ожидания не маскировались изменением исходного теста.

## Что ещё нужно проверить перед выпуском

Windows Setup собирается из текущего x64 payload с исходным установщиком из архива. Реальная установка/обновление/удаление в Windows, экранный диктор, 100/150/200% DPI, тихий режим и живое воспроизведение через музыкальные сервисы в этой Linux-среде не проверены. Пройдённые браузерные тесты используют стабы сервисов и не подтверждают фактическую авторизацию или воспроизведение.

```sh
npm ci
npm run build:graphics
npm test
npm run test:experience
npm run dist
```

Для теста Chromium можно указать абсолютный путь через `CHROMIUM_PATH`. Подробнее об импорте установщика: `INSTALLER-IMPORT-1.0.0.md`.
