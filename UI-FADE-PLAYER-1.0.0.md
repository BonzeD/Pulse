# Pulse 1.0.0 — затухание визуала и анимация панели

Новая пересборка версии **1.0.0**, основанная на последнем выданном архиве. Предыдущие исправления и откат текста сохранены. В renderer изменены только ui-fixes.css и ui-fixes.js.

## Изменения

1. Маска затухания привязана к видимым краям музыкальной сцены, а не к увеличенному Canvas. У Canvas запас по 64 px больше не смещает градиент за место окончания рисунка. Слева и справа визуал плавно достигает нулевой непрозрачности в пределах сцены. Direct WebGL использует ту же маску с нулевым запасом. Ширина перехода адаптивная: 56–180 px. Сверху визуал по-прежнему может заходить за рамки под UI. Новых настроек краёв нет.
2. Скрытие панели: лёгкое уменьшение до 96%, сдвиг вниз и растворение. Возврат — плавный подъём с восстановлением размера и прозрачности. Видимость выключается только после завершения выхода, но ввод отключается сразу. Используются независимые translate/scale: существующее горизонтальное центрирование панели не ломается. Повторное переключение разворачивает текущий переход без телепортации.
3. Кнопка «Показать плеер» появляется при наведении на нижнюю центральную область шириной до 360 px и высотой 104 px. При уходе курсора исчезает. На узком окне зона сужается. Невидимая зона не перехватывает клики и прокрутку лежащей под ней страницы.
4. Для клавиатуры сохранены Ctrl+Shift+B и доступ по Tab/Enter. При клавиатурном фокусе кнопка видна даже вне зоны наведения. Отключённые анимации и системное уменьшение движения отрабатывают без переходов.

## Проверки

- `npm test`: **97/97**.
- `CHROMIUM_PATH=/usr/local/bin/chromium npm run test:fade-bar`: **7 сценариев**. Затухание проверено не только по CSS, но по пикселям скриншота непрозрачной тестовой заливки на обоих холстах: яркость по мере удаления от каждого края 1 → 13 → 51 → 125 → 255. За пределами сцены — 0.
- Проверены реальные промежуточные кадры выхода/возврата, отложенное скрытие, немедленный inert, прерывание перехода, наведение и уход из зоны, клавиатура, Full/Clean, «Только текст» и оба режима уменьшения движения.
- `tests/ui-fixes.cjs`: **17 UI-сценариев**, без ошибок выполнения; тесты возврата панели теперь сначала наводят курсор в нужную область.
- `tests/hotfix-ui.cjs`: **4 расширенных сценария**, включая все пресеты, оба direct GPU-пути, настройки и живое движение воды.
- `tests/motion-ui.cjs` и `tests/audio-signal.cjs`: пройдены.
- Совпадение всех прочих renderer-файлов с предыдущим выданным исходником проверено побайтно. Текстовые движки, пресеты визуалов, аудио и сетевые модули этой правкой не менялись.

## Сборка

После проверок выполнен `DOTNET=/data/dotnet/dotnet npm run dist`: Windows x64 portable и установщик, версия 1.0.0. Содержимое пакетов сверяется с рабочими исходниками и исходным ZIP; SHA-256 приложены отдельно.

Проверки интерфейса выполнены на Linux/Chromium с тестовым IPC. Запуск и установку на настоящем Windows в этой среде проверить нельзя. Бинарники не подписаны сертификатом, как и в исходной конфигурации.
