# Pulse 1.0.0 — основной пресет автора

Эта пересборка завершает ожидавшее файла подключение пресета, описанное в историческом `DOWNLOAD-PRESET-1.0.0.md`. Предыдущие исправления локальной музыки, загрузчика, установщика, ссылок и интерфейса сохранены.

## Источник

Полученный `pulse-settings.json` сохранён как тестовый эталон `tests/fixtures/primary-preset.json`.

SHA-256 исходного файла: `cad1219ad676b414674f29417623f6a530a504dc7fed80ca4bdd9d66359b9d93`.

В файле 18 разделов настроек и параметры `vizStyle`, `mode`, `tab`, `mini`. Ключ Spicy Lyrics пуст; аккаунтов, библиотеки и личных путей в поставляемом пресете нет. `renderer/primary-preset.js` содержит ту же структуру значений; эталон и поставляемые значения проверяются на полное совпадение.

## Поведение

- **Новый профиль** без объекта сохранённых настроек получает весь присланный набор. В том числе: русский язык, 144 FPS, DPR 2, задержку `playback`, Майнрадио Ultra, панель 381 px, отражения и оформление, выбранный визуал `wave`, режим `visual`, вкладку `lyrics`.
- **Существующий профиль** не получает принудительный сброс при обновлении. Его настройки загружаются с прежними резервными значениями для отсутствующих полей.
- Эффективные заводские значения теперь авторские: сбросы разделов используют этот набор. Полный сброс настроек при следующем запуске также создаёт профиль с авторскими значениями.
- Внизу **Настройки → Основные**, в группе «Резервная копия и сброс», активна кнопка **«Основной пресет»**. В простом режиме группа может быть свёрнута в «Дополнительно».
- Кнопка спрашивает подтверждение, атомарно сохраняет весь набор и перезапускает Pulse. Перезапуск необходим, чтобы применились и стартовые параметры, включая задержку AudioContext и выбор клиента, без полуприменённого состояния.
- Треки, плейлисты, очередь, локальная библиотека, правки метаданных, тексты, сдвиги, данные аккаунтов и существующий ключ Spicy Lyrics не заменяются.
- Список пользовательских конфигов сохраняется. Активный конфиг снимается с выбора, чтобы автосохранение не перезаписало его авторским набором.
- При отказе в подтверждении изменений нет. При ошибке атомарного сохранения старые настройки восстанавливаются в памяти; перезапуск не выполняется. Повторный быстрый клик не создаёт несколько перезапусков.

Параметры, которых нет в предоставленном файле (например, внутренние данные сторонних плагинов или отдельное хранилище самого Майнрадио), не выдумываются и не стираются. Настройки хранятся в `%APPDATA%\Pulse\library.json`, раздел `library.settings`.

## Проверки

- **133/133 Node-теста**, включая точное совпадение пресета с файлом автора, неизменность данных, клонирование вложенных объектов, первый запуск, сохранение существующего профиля, отказ, ошибку записи и порядок «сохранение → перезапуск».
- **8 сценариев UI пресета**: первый запуск, изменение и повторный запуск без автосброса, существующий профиль, отмена, ошибка записи, реальный клик кнопки, повторная загрузка сохранённого набора, минимальный поддерживаемый размер окна 980×640. Превью также проверено при 1366×768.
- Повторные отдельные проверки локальных треков, редактора метаданных, копирования ссылок, панели Майнрадио, затухания, анимаций и звукового сигнала.
- UI-стенд имитирует IPC-перезапуск и затем реально перезагружает страницу с сохранёнными данными. Нативную установку/UAC и перезапуск Windows-процесса следует дополнительно проверить на Windows; Linux-стенд не заменяет эту проверку.

Версия приложения и имена файлов по просьбе автора остаются **1.0.0**. Пересборка различается по SHA-256.
