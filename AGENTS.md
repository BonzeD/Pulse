# Правила для ИИ-агентов и разработчиков Pulse

Обязательные актуальные правила: [FOR AI.md](FOR%20AI.md).

## Версия — фиксированная 1.0.0
По прямой просьбе автора версия приложения остаётся **1.0.0**. Не повышать и не менять её без явной просьбы автора, в том числе при исправлениях и пересборке.

- Сохранять 1.0.0 в package.json, корне package-lock.json и packages[""], renderer/api.js, renderer/mineradio-host.js, значениях по умолчанию установщика и его графики.
- Файлы: Pulse-1.0.0-source.zip, Pulse-1.0.0-portable.exe и Pulse-Setup-1.0.0.exe.
- Различать пересборки по SHA-256 и описанию изменений, а не автоматическим повышением версии.
- Исторические отчёты и baseline-файлы не переписывать.

## Сборка
- `npm install`, затем `npm run dist` (portable через electron-builder + установщик через `build/make-setup.sh`).
- Сборка работает на Linux без wine: иконка ставится через `resedit` (`build/afterPack.js`), установщик — linux-`makensis`.

## Стиль кода
- Не ломать существующие настройки пользователя (`lib.settings`): новые опции — с безопасным значением по умолчанию.
- Тексты приложения локализуются; новые ключи добавлять в словарь. Сохранять исходный дизайн и сценарии установщика. По последнему запросу автора все видимые тексты установщика и деинсталлятора переведены на английский.
