# Раскладка репозитория

- Приложение, его package.json, lockfile, runtime-модули, renderer, build, native, resources, tests и tools находятся в `app/`.
- Корневой package.json — только обёртка npm-команд. `npm ci`, `npm test`, `npm start`, `npm run dist` запускаются из корня; зависимости ставятся в app/node_modules.
- В app/ все внутренние пути сохранены. Относительные пути к runtime-файлам ниже читать от app/, к историческим отчётам — искать в docs/history/.
- Документация находится в docs/, отчёты — docs/history/, прежние манифесты — docs/manifests/. Исторические отчёты и baseline-файлы не переписывать.
- GitHub Actions остаётся в корневой .github/; сборка исполняется из app/; результат — app/dist/.

# Правила для ИИ-агентов и разработчиков Pulse

Обязательные актуальные правила: [FOR AI.md](docs/development/FOR%20AI.md).

## Версия — только по просьбе автора
Номер версии повышать только по явной просьбе автора. Исправления и пересборки сами по себе не означают повышение версии.

- Текущая запрошенная версия: **1.0.1**. Согласовывать package.json, lockfile, API/host и метаданные установщика.
- Имена portable, Setup и source ZIP формировать из текущей версии.
- Исторические отчёты и baseline-файлы не переписывать.
- Не публиковать GitHub/release без отдельной команды автора.

## Сборка
- `npm install`, затем `npm run dist` (portable через electron-builder + установщик через `build/make-setup.sh`).
- Сборка работает на Linux без wine: иконка ставится через `resedit` (`build/afterPack.js`), установщик — linux-`makensis`.

## Стиль кода
- Не ломать существующие настройки пользователя (`lib.settings`): новые опции — с безопасным значением по умолчанию.
- Тексты приложения локализуются; новые ключи добавлять в словарь. Сохранять исходный дизайн и сценарии установщика. По последнему запросу автора все видимые тексты установщика и деинсталлятора переведены на английский.

## Текущая ветка отката
Историческая основа — стабильная 2.0.12 пользователя; текущую маркировку выпуска определяет раздел «Версия». Не переносить обратно экспериментальные сетевые и GPU-патчи. История и контрольные суммы базовых файлов лежат в tests/stable-baseline.json.

## Аудит 1.0.1
Версия определяется последней явной просьбой автора (см. раздел выше). Порт островка удалён. Исправления безопасности и обновление Electron документированы в AUDIT-1.0.1.md. Исторические baseline-файлы не перезаписывать: точные изменения playback проверяются в tests/regression.cjs, поведение — tests/audit.cjs.
