# Pulse 1.0.0 — перетаскивание мини-виджета

## Изменение

Контейнер `.w` больше не объявляет прямоугольник `no-drag` размером со весь виджет. Такая область конфликтует с отдельной фоновой зоной `drag-region` при нативном hit-testing. У контейнера удалено объявление `app-region` (значение computed style по умолчанию — `none`), фон — `drag`, а название, исполнитель и текст песни явно отмечены как области перетаскивания.

Кнопки, вложенные SVG, обложка, полоса прогресса и громкость остаются `no-drag`. Контейнер кнопок не сделан draggable. Настройка «Закрепить на месте» отключает все зоны перетаскивания; предпросмотр редактора никогда не перемещает окно.

Версия остаётся 1.0.0. Код воспроизведения, установщика, качество и лимит FPS не изменены. Исправления переводов из предыдущей сборки сохранены.

## Проверки

- Unit-регрессия проверяет нейтральный контейнер, отдельную фоновую область, текстовые drag-зоны и запрет drag для кнопок.
- Chromium-тест проверяет mini/standard/large, закрепление on/off, реальную верхнюю DOM-цель на заголовке, работу кнопок и ползунков, масштабированные контролы и отключение drag в предпросмотре.
- Проверки CSS/DOM не заменяют нативный Windows-прогон. После установки проверить физическое движение окна мышью, сохранение позиции после перезапуска, кнопки и переключатель закрепления на целевом Windows-ПК.

Результат прогона исходников: 261 unit/regression-проверка прошла, 1 проверка генерируемой графики пропущена до сборки. Chromium: 97 проверок указателя/команд прошли; ошибок страницы нет.

## Как перемещать

Отключить **Настройки → Виджет → «Закрепить на месте»**. Зажать левую кнопку мыши на названии трека, исполнителе, тексте песни или свободном фоне и перетащить. Кнопки, обложка и ползунки не являются ручками перемещения.

## Пересборка

Для этой CSS-доработки неизменённый `PulseMediaBridge.exe` и его notices взяты из предыдущего проверенного билда. Electron-приложение, portable и Setup пересобираются заново с актуальными исходниками; исходный установщик не изменяется. Чистая сборка из исходников по-прежнему использует `npm run dist` и .NET SDK 8.
