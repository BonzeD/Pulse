# Pulse 2.0.10 — аудит интерфейса и карта функций

Контрольный список «без потерь» для редизайна. Собран по исходникам и headless-прогону (`/data/tools/ui.js`: Playwright + заглушка `window.pulse` с фейковым каталогом).

## 1. Экраны, снятые до и после
Главная, Обзор, Библиотека, Моя волна, Поиск, Артист, Альбом, Диджей, Скачанное, Настройки (Основные, Текст песен, Внешний вид, Интерфейс, Визуализатор, Звук, Виджет), Плеер (Песня, Визуал, Текст), «Только текст», командная палитра; окна 1440×900 и 900×700, каркас «Панели» и «Классический».

## 2. Что нашлось при аудите

### Ошибки (механики, которые молча не работали)
- `applySettings()` в `app.js`: с 2.0.4 часть строки оказалась **внутри комментария** — при запуске не применялись «Компактный вид» (`look.compact`), «Фон из обложки» выкл. (`look.ambient` → `no-amb`), заливка текста (`ly.fill`), класс `no-dj`. С 2.0.6 так же пропали `Viz.setDpr` («Чёткость визуала»), `data-viz-edge` («Края визуала») и сброс кэша прокрутки. **Исправлено в 2.0.10.**

### Дубли и конфликты
- Настройки текста живут в четырёх местах: «Настройки → Текст песен», всплывашка «Вид текста» (Aa), «Эффекты визуала», «Вид» в «Только текст». Это осознанно (настройки по месту), но во всплывашках не было пути к полному списку → добавлена кнопка **«Все настройки…»**.
- «Размывать дальние», «Свечение», анимация слов — и в «Тексте песен», и в Spicy-блоке; вместо поиска нужного набора ползунков — **готовые виды текста** (Классика / Spicy / Караоке / Минимум).
- В нижнем плеере 13 кнопок одновременно; «Скачать» и «Не нравится» дублируют пункты меню «⋯», кнопка диджея видна и при выключенном диджее.
- Один и тот же компонент (кнопка, чип, сегмент, переключатель) переопределялся в 3–6 слоях CSS.

### CSS
- 15 слоёв, 8 252 объявления, 240 `!important` (больше всего: `pulse3` — 44, `spicy` — 32, `lysbar` — 27, `studio` — 21).
- **306 объявлений гарантированно перебиты** позже тем же селектором в том же `@media` (то же свойство или его сокращение, не слабее по `!important`, значение валидно в Chromium) и **72 правила после этого пустые**. Удалены инструментом `tools/cssdead.js`; скриншоты 21 экрана до/после чистки совпали попиксельно (отличия только в анимированных частицах).
- Правила, перебитые *другим* селектором, автоматически не удалялись — это следующий этап (по одному экрану, с проверкой скриншотами).

## 6. Что сохранено как публичный API
- id и классы: `#bar #pp #side #view #top #lyrics #barMid #seek #stage #artWrap #visLine #ppTabs`, `.ly-line .w .cur .past`, `.nv .card .tr .chip .btn .seg .toggle` — без изменений.
- Регионы редактора `CZ_REGIONS` — те же селекторы; сохранённые раскладки работают.
- `PX.on/emit`, `Pulse.addSettingsTab`, `Pulse.layout` — без изменений.
- Ключи `lib.settings` не переименованы. Новые: `ui.shell`, `ui.barAll`, `ui.setMode`. Миграция `_m2010`: старые цвета по умолчанию (`ui.bg = #030303`, `ui.panel = #212121`) один раз меняются на новые; свои цвета не трогаются.
