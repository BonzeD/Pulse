# Pulse — дизайн-система (с 2.0.10)

## Принципы
1. **Одна система значений.** Цвета, отступы, радиусы, шрифты, тени и длительности — только из `renderer/ds.css` (`--ds-*`).
2. **Главное на виду, редкое — на шаг глубже.** Ничего не удаляется: редкое уходит в «⋯», «Дополнительно» или командную палитру.
3. **Анимации — только `transform` / `opacity` / цвет.** Длительности из токенов; `no-anim` обнуляет их, «Экономно» укорачивает. Новых постоянных `filter: blur` нет.
4. **Доступность.** Текст не ниже 4.5:1 (`--ds-t3` ≈ 5.5:1), видимый фокус с клавиатуры (`--ds-focus`), подсказки у иконок, цели ≥ 32 px.

## Токены (`ds.css`)
| Группа | Токены |
|---|---|
| Поверхности | `--ds-bg` (от «Цвета фона»), `--ds-s1` панели, `--ds-s2` карточки/поля, `--ds-s3` наведение, `--ds-s4` нажатие, `--ds-pop` меню и всплывашки, `--ds-line`, `--ds-line2` |
| Текст | `--ds-t1` основной, `--ds-t2` второстепенный, `--ds-t3` подписи |
| Акцент | `--ds-acc`, `--ds-acc2`, `--ds-accS`, `--ds-grad` — из обложки (`--a1/--a2`) |
| Отступы | шаг 4 px: `--ds-1…--ds-12`, зазор между панелями `--ds-gap` |
| Радиусы | `--ds-r1` 6 · `--ds-r2` 10 · `--ds-r3` 14 · `--ds-r4` 20 · `--ds-rf` круг |
| Шрифт | `--ds-f1` 12 · `f2` 13 · `f3` 14 · `f4` 16 · `f5` 22 · `f6` 32; веса `--ds-w1…w3` |
| Тени | `--ds-sh1…sh3` |
| Движение | `--ds-fast` .14s · `--ds-med` .24s · `--ds-slow` .42s · `--ds-ease` · `--ds-spring` |

## Компоненты (`ui.css`, часть 1)
Кнопка `.btn` (`.w` основная, `.acc` акцентная, `.ghost`, `.sm`), иконка `.ib`, чип `.chip`, сегменты `.seg`, переключатель `.toggle`, поле `.field/.xin`,
меню `.menu`, всплывашка `.pop-panel` (+ низ `.pop-f` с «Все настройки…»), модальное окно `.modal-box`, тост `.toast`, карточка `.card`, строка трека `.tr`,
полка `.shelf/.sh-title`, вкладки `.tabs`, пустое состояние `.empty`, скелетон `.ds-skel`, «Дополнительно» `details.set-adv`, палитра `.ds-pal`.

## Каркас «Панели» (`body.ds-panels`, `ui.css`, часть 2)
- Меню слева, страница, плеер и страница плеера — отдельные скруглённые панели с зазором `--ds-gap` на фоне окна; верхняя панель прозрачная.
- Нижний плеер: слева — песня (обложка, название, ♥, ⋯), по центру — 🔀 ⏮ ▶ ⏭ 🔁 и перемотка со временем по краям, справа — громкость, диджей (если включён), ⌃.
- «Скачать» и «Не нравится» — в «⋯» (они там и были). Вернуть на панель: «Интерфейс → Все кнопки на панели плеера».
- «Классический» каркас (как до 2.0.10): «Интерфейс → Вид окна → Классический». Кнопки возвращаются на прежние места.
- «Только текст» (`body.lys-bar`) и полноэкранный режим каркас не трогает.

## Изменения по экранам (2.0.10)
| Экран | Что изменилось |
|---|---|
| Оболочка | панели, прозрачная шапка, поиск-«таблетка» с подсказкой Ctrl K, подпись «Плейлисты» в меню |
| Нижний плеер | управление по центру, перемотка под кнопками, меньше кнопок на виду |
| Главная | большая карточка «Продолжить» (текущий трек) + «Моя волна», дальше полки |
| Настройки | «Простые / Все настройки»; в простом режиме редкие группы свёрнуты в «Дополнительно»; «Готовый вид текста»; «Каркас окна» в «Интерфейсе» |
| Всплывашки | «Готовый вид» в «Виде текста», «Все настройки…» внизу |
| Везде | командная палитра Ctrl+K, единый вид кнопок/чипов/сегментов/переключателей/меню, фокус с клавиатуры |
