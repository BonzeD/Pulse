# Сборка Pulse 1.0.0 с дополненной локализацией

Новые Windows x64 portable и установщик собраны из исходников последнего localization-draft. Номер 1.0.0 сохранён по явному запросу автора для первого публичного выпуска. Не путать с ранее выданными EXE того же предварительного номера: контрольные суммы новых файлов приведены ниже.

## Выполнено
- Восстановлен последний выданный архив исходников; проверен SHA-256 c2814dbda0518a80cc199e993e3151e7e72177fc43e5603d774d94998dfad8e4.
- `npm ci`, .NET 8 self-contained Windows x64 медиамост и `npm run dist` успешно выполнены в Linux.
- `npm test`: 73 pass, 0 fail, 0 skipped.
- Повторно прошли `tests/locale-sweep.cjs` (EN/JA) и `tests/chrome-ui.cjs`; неожиданных русских надписей в проверенных сценариях и ошибок JavaScript не обнаружено. Русские тестовые названия песен оставлены как контент.
- 123 упакованных файла app.asar побайтово совпали с рабочими исходниками; package.json проверен отдельно: 1.0.0, Bon_zeD & Daswi. Версия и CompanyName в Pulse.exe проверены.
- Внешний NSIS-контейнер portable и установщик успешно проверены полным 7-Zip. Вложенный 7z portable также прошёл проверку; сообщение о данных за концом архива относится к структуре самораспаковывающегося EXE.
- app.asar и PulseMediaBridge.exe извлечены из обоих конечных EXE: SHA-256 совпадают с проверенным unpacked-пакетом.
- GPU-файлы viz.js, neon-gpu.js и gpu.js совпадают с последним выданным архивом. Экран установщика с версией 1.0.0 просмотрен.
- Включены дополненные переводы, авторы Bon_zeD/Daswi и раскрытие помощи Claude, ChatGPT, Notion AI. Удаление неуточнённых кнопок со скриншота не выполнялось.

## Ограничения
Сборки без цифровой подписи. Реальный запуск приложения, установка/удаление, Windows WinRT/GSMTC и Windhawk здесь не проверены. Успешная компиляция и проверка упаковки не доказывают совместимость: перед публикацией выполнить `docs/windows-media-session.md` в Windows. GitHub Actions и публичный Release не запускались.

npm сообщил 8 moderate vulnerabilities; автоматический `audit fix --force` не применялся. Этот выпуск не означает нового полного аудита безопасности зависимостей.

Сборочные скрипты в исходниках по-прежнему используют sh и рассчитаны на Linux-окружение; `npm run dist` в обычном PowerShell без адаптации не работает. Готовые EXE запускать через npm не требуется.

Логи: `audit-evidence/localization-build-1.0.0`. Прежние каталоги audit-evidence содержат исторические отчёты, не результаты новых EXE.
