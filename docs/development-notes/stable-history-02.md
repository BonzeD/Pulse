# Pulse 1.9.3 — отдельный редактор и редактор всего приложения

## Почему в 1.9.2 «ничего не двигалось»
Перетаскивание жило внутри iframe предпросмотра (в Electron события мыши там теряются), а ограничения по краям
почти не давали двигать широкие блоки. Теперь iframe только рисует, а мышь ловит прозрачный слой поверх него
в самом окне настроек; хит-тест и превью идут через `pvApi` фрейма.

## Новое
- **Настройки → Редактор** — отдельная вкладка: большой живой холст + панель. Режимы: Виджет, Приложение, Обои,
  Discord, Текст, Визуал, Интерфейс. Меню настроек на этой вкладке сворачивается в иконки, чтобы холст был крупнее.
  Открыть: кнопка «Открыть в редакторе» у любого маленького предпросмотра или **Ctrl+E**.
- **Виджет**: каждый элемент отдельно (обложка, название, исполнитель, строка песни, каждая кнопка, громкость,
  прогресс, время) — клик выбрать, тянуть двигать, колесо — размер, Delete — скрыть, стрелки — точно (Shift ×10),
  Ctrl+Z / Ctrl+Y. Свои позиции для каждого размера (Мини / Стандарт / Большой). Старые сдвиги переносятся.
- Во вкладке «Мини-виджет» остался только маленький предпросмотр (без редактора).
- **Редактор приложения** (Редактор → Приложение, Кастомизация → «Открыть редактор», **Ctrl+Shift+E** из любого места):
  прямо в окне Pulse выбираешь любую часть — верхнюю панель, поиск, логотип, меню слева и его пункты, полки и карточки
  на Главной / Обзоре / Библиотеке, плеер внизу и любые его кнопки, экран плеера (обложка, визуал, текст, вкладки).
  Пока редактор открыт, клики не доходят до приложения. Alt+клик или «↑» — выбрать родительский блок.
  Правки страниц привязаны к своей странице. Внизу — панель: переход между страницами, размер, скрыть, на место,
  отмена/повтор, «Сбросить всё», «Готово».
- Всё хранится в `layout.items`, входит в конфиги; «Вернуть исходный вид» сохраняет копию в «Конфиги».
