# Pulse 2.0.3

## Треки загружаются быстрее — yt-dlp только для скачивания
- Для прослушивания yt-dlp больше **не запускается вообще** (он стартовал по 4–8 секунд и тормозил загрузку треков).
  Звук берётся прямым запросом к YouTube — за доли секунды. Если один способ не сработал, Pulse пробует ещё два
  (разные клиенты YouTube), а если YouTube не отдал звук совсем — сам переключается на встроенный YouTube, как раньше.
- yt-dlp теперь нужен только для **офлайн-загрузок** (кнопка «Скачать») и для входа «из браузера».
- Фоновая предзагрузка следующего трека тоже больше не запускает yt-dlp — компьютер не грузится в фоне.

## Аккаунты разделены по сервисам
- У **YouTube Music, Apple Music и Spotify — свои аккаунты** и свой список для быстрого переключения.
- Аватарка справа вверху показывает аккаунт **того сервиса, который открыт сейчас** (вкладка в боковом меню):
  в Spotify — аккаунт Spotify, в Apple Music — Apple, в YouTube Music — Google. Там же — переключение и «Добавить аккаунт».
- Настройки → **Аккаунты** (менеджер): три отдельных раздела — YouTube Music, Apple Music, Spotify.
  Можно держать несколько аккаунтов каждого сервиса и переключаться одним кликом. Вход хранится зашифрованным.
- Если вход в новый аккаунт отменить — возвращается прежний аккаунт этого сервиса.

## Лайки сохраняются на сервере, «Мои треки» убран
- Плейлист **«Мои треки» убран**. Лайк (♥) теперь уходит в аккаунт сервиса, из которого трек:
  «Понравившиеся» YouTube Music, «Любимые треки» Spotify, медиатека Apple Music.
- Нет входа или интернета — лайк не теряется: он ждёт в очереди и отправится сам после входа / когда появится сеть.
- Лайки, поставленные в самом сервисе (на телефоне, в браузере), тоже горят сердечком в Pulse.
- Треки, которые были в «Моих треках», автоматически становятся лайками и уходят на сервер (после входа в аккаунт).

## Текст песни: светится само слово, а не «фон»
- Свечение больше не расплывается пятном за строкой: светится **только слово, которое поют сейчас**, плотно по контуру букв.
  Уже спетые слова — просто белые. Во время караоке-заливки светится только залитая часть слова.
- То же в «Только текст»: свечение слова — по буквам, сила и цвет настраиваются.

## Оптимизация: «Визуал» и караоке
- Размытый фон из обложки (за плеером, в приложении и в «Только текст») теперь готовится **один раз** картинкой,
  а не пересчитывается каждый кадр CSS-размытием на весь экран — это была главная причина падения FPS.
- Пульс «в такт» обновляет только обложку и текущую строку, а не весь плеер (раньше каждый кадр пересчитывались
  стили сотен элементов и перерисовывалось свечение текста).
- Положение обложки для визуала больше не измеряется каждый кадр (принудительный пересчёт раскладки).
- Визуализатор сам облегчает свечение, если реальная частота кадров заметно ниже возможной (раньше замечал только
  медленный код, но не тяжёлое рисование видеокартой).
- «Только текст»: рябь на воде больше не пересчитывает шум каждый кадр, цвет частиц не читается каждый кадр,
  полоска прогресса двигается без пересчёта раскладки.

## «Только текст»: исправлены отражения
- Отражение — теперь живая копия текста: слова в воде появляются **одновременно** с текстом (раньше отражение
  показывало ещё не спетые слова), уходящая строка уходит и в отражении.
- Пропал светлый прямоугольник вокруг «горящего» слова в воде.
- Новые настройки отражения: яркость и размытие.

## «Только текст»: новые эффекты (Настройки → Текст песен)
- **Цвет текста**: белый, цвет обложки, градиент.
- **Свечение слова**: сила (0–200 %) и цвет (цвет обложки / белый).
- **Пульс на басах** и **тряска на ударах** — с регулировкой силы.
- **Хроматический сдвиг** — красно-голубой «разъезд» у поющегося слова.
- **Контур у неспетых слов** (в «Классике»).
- Новые анимации появления слов: **Сверху**, **Переворот**, **Сбоку**, **Из глубины**.
- **Затемнение фона** — регулируется.
- **Частицы**: пылинки, снег, звёзды, пузырьки + количество.

## Для разработчиков
- `offline.js`: `resolveStream` — только InnerTube (ANDROID_VR ×2, IOS), без `ytdlpResolve`; yt-dlp — в `run()` (загрузки).
- `services.js`: `svcAcc` — менеджер аккаунтов Apple Music / Spotify (`accounts-am.json`, `accounts-sp.json`).
  IPC `accm:*` принимает сервис последним аргументом (без него — YouTube Music, как раньше).
- `renderer/app.js`: `lib.likes`, `lib.likeQ`, `flushLikes()`, `pullLikes()`; `mine()` оставлен только для чтения (плагины).
- Новый файл стилей `renderer/v203.css`. Изменения отмечены комментариями `// 2.0.3:`.
