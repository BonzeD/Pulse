# Pulse 2.0.2

Pulse стал **клиентом трёх сервисов**: YouTube Music, Apple Music и Spotify. Это не платформа и не «перенос» —
плейлисты не импортируются, вы просто открываете нужный сервис прямо в Pulse и слушаете его каталог и медиатеку.

## Переключение сервиса
- Переключатель — только логотипы; выбранный сервис подсвечивается плашкой его цвета, которая плавно переезжает,
  логотип «подпрыгивает», страница появляется с мягкой анимацией.
- Переключатель **YouTube Music / Apple Music / Spotify** в боковой панели (над меню) и в Настройки → **Клиент**.
- При смене сервиса Pulse возвращается на главную, и всё дальше берётся из выбранного сервиса:
  главная, поиск и подсказки, исполнители, альбомы, плейлисты, «Обзор» / настроения, чарты, новинки, радио «Далее» и похожие треки.
- Ссылки Apple Music и Spotify, вставленные в поиск, открываются сразу (трек, альбом, плейлист, исполнитель).
- Кэш страниц хранится отдельно для каждого сервиса, ничего не смешивается.

### Что работает без входа
- **Apple Music** — каталог полностью: главная (топ песен, плейлисты, альбомы), поиск, исполнители, альбомы, плейлисты, радио.
  Регион витрины — «Авто» или вручную в Настройки → Клиент.
- **Spotify** — каталог полностью: главная, «Обзор» (настроения и жанры), Топ-50, новинки, поиск, исполнители, альбомы, плейлисты, радио.

### Вход в Spotify — через браузер
- Встроенное окно Spotify не пускало через Google («браузер небезопасен»). Теперь для Spotify — то же окно входа, что и для YouTube Music:
  **Войти через браузер** — открывается браузер по умолчанию (можно выбрать другой: Edge, Chrome, Firefox, Brave, Яндекс, Vivaldi, Opera).
  Входишь в Spotify любым способом — Google, почта, Apple, Facebook. Других вариантов в окне входа Spotify больше нет.
- **Firefox открывается в твоём обычном профиле**, а не в новом пустом пользователе (для YouTube Music тоже):
  если ты уже вошёл в сервис в Firefox — вход подхватывается сразу, без окон; если нет — открывается вкладка входа,
  и Pulse сам замечает вход. Закрывать Firefox не нужно.
- Chromium-браузеры (Edge, Chrome и др.) по-прежнему открывают отдельное окно — войди и закрой его.
- Вход засчитывается, только если Spotify действительно узнал аккаунт; устаревший вход не сохраняется.
- После входа тексты, которые раньше пришли «из запасных баз», перепроверяются — появляются тексты Spotify.
- Окно входа через браузер больше не «зависает», если браузер был закрыт аварийно (Linux / macOS).

### Что даёт вход в аккаунт
- **Apple Music** (нужна подписка): медиатека, свои плейлисты, «Нравится», тексты песен Apple Music.
- **Spotify**: «Любимые треки», свои плейлисты, недавно прослушанные, альбомы и подписки, «Нравится», тексты песен Spotify.
- Вход и выход — в Настройки → Клиент. Аккаунт YouTube Music работает как раньше.

## Откуда звучит музыка
- Apple Music и Spotify отдают музыку только в своих приложениях (защита DRM), поэтому звук для их треков
  берётся из **той же записи в YouTube Music**. Подбор: сначала по коду записи ISRC, затем по исполнителю,
  названию и длительности (ремиксы, live, slowed и т. п. не путаются с оригиналом).
- Найденные соответствия запоминаются — повторное воспроизведение и загрузки работают сразу.
- Офлайн-загрузки, «Видео», Discord, копирование ссылки работают и для треков Apple Music / Spotify
  (ссылка и кнопки Discord ведут в исходный сервис).

## Текст песен — выбор источника
- Настройки → Текст песен → **«Откуда брать текст»**: **Все источники** (по умолчанию), **YouTube Music**, **Apple Music**, **Spotify**.
- Источник можно сменить прямо в плеере — нажмите на подпись источника под текстом,
  и в визуальном режиме — чипом источника в панели управления.
- «Все источники» сравнивает Apple Music, Spotify, YouTube Music, Musixmatch, NetEase и LRCLIB и берёт лучший вариант
  (пословная синхронизация важнее построчной, построчная — важнее обычного текста).
- Если в выбранном сервисе текста нет — показывается лучший вариант из Musixmatch, NetEase или LRCLIB с пометкой об этом.

### Исправлена синхронизация текстов Spotify
- Запрос текста — как у веб-плеера Spotify; конец строки — начало следующей (как в самом Spotify), строки «♪» — паузы.
- Для треков YouTube Music текст Spotify берётся только у записи почти той же длины (±3 с, ближайшая по длительности) —
  тексты от radio edit и других версий больше не «уезжают».
- Если звук трека Spotify взят из клипа с интро — тайминги сдвигаются на длину интро; при сильном расхождении берётся другой источник.
- Бесплатный аккаунт, которому Spotify отдаёт только начало текста, больше не получает обрезанный текст — берётся полный из других баз.
- Караоке-заливка слова идёт цветом Spotify, когда включены «Цвета текста Spotify».

### Тайминги и эффекты
- **Apple Music** — пословная синхронизация, бэк-вокал (в скобках, своим цветом и со своими таймингами),
  дуэты (партии разных исполнителей выравниваются по разным сторонам), авторы текста в конце.
- **Spotify** — синхронизация по слогам/строкам и фирменные цвета фона и текста песни (можно выключить).
- **YouTube Music** — синхронизированный текст по строкам, если его нет — обычный текст.
- Новые переключатели в Текст песен: бэк-вокал, цвета Spotify, авторы текста.
- Все тексты по-прежнему сохраняются в обычном формате — работают корректор, офлайн и виджет.

## Убрано
- Импорт плейлистов из сервисов убран: Pulse — клиент, а не платформа.
- **Распознавание текста нейросетью (Whisper) убрано** полностью: кнопки «По голосу» / «Распознать по голосу», настройки нейросети,
  фоновая подготовка текста для офлайна. Установщик стал меньше; скачанные модели (до 760 МБ) удаляются из папки Pulse сами.
  Тексты без времени по-прежнему раскладываются по ритму; «Притягивать слова к голосу», корректор и запись по нажатию остались.

## Установщик
- Возвращён собственный тёмный установщик Pulse (`build/installer.nsi`, графика из `build/installer-ui`).
  `sh build/make-setup.sh` сам перерисовывает картинки при смене версии.

## Для разработчиков
- Удалены `whisper.js`, `lyralign.js` и `resources/whisper`.
- Новый модуль `services.js` (Apple Music, Spotify, сопоставление с YouTube Music, тексты сервисов),
  в интерфейсе — `renderer/clients.js` и `renderer/clients.css`. Изменения отмечены комментариями `// 2.0.2:`.
- Spotify работает через внутренний API веб-плеера; если Spotify обновит его, Pulse сам подтягивает новые
  ключи запросов из веб-плеера (не чаще раза в час).
- Каталог без входа проверен; функции, требующие входа в Apple Music / Spotify, написаны по их API,
  но без тестовых аккаунтов проверены не были.
