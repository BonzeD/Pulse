# Pulse 2.0.12

## Убрано
- «Аврора» (северное сияние на фоне из 2.0.11) — удалена полностью: файл, настройка, стили.

## Новое: «Припевы»
- Pulse сам находит припевы: по повторяющимся блокам синхронного текста, а без текста — по громкости трека.
- Метки припевов на полосе перемотки, кнопка «К припеву» рядом с «Следующий» (появляется, когда припев найден).
- Клавиша **C** — к следующему припеву, **Shift + C** / правый клик по кнопке — «Только припевы»:
  каждый трек начинается с припева и после него переключается дальше (быстрый просмотр плейлиста или волны).
- Настройки: «Звук → Припевы». Действия есть в Ctrl + K.

## Новое: «Кабина самолёта» (вкладка «Остальное»)
- Кнопка «Кабина» рядом с «Песня / Видео / Визуал». Вид из окна в цветах обложки (обложка — солнце),
  земля бежит в темпе BPM, крен — от бита; HUD на стекле со строкой текста; 6 приборов.
- Работает каждая кнопка: ENGINE — play/pause, РУД — громкость, NAV — треки, TRIM — ±10 с, ручка HDG — перемотка,
  GEAR — перемешивание, FLAPS — повтор, AP — «Моя волна», LDG LIGHTS — лайк, EJECT (с крышкой) — «Не нравится»,
  SPD BRK — скорость 0.9×, SEAT BELTS — текст на стекле, WIPERS — дворники, PANEL LT — подсветка,
  CABIN — объявление командира, MASTER CAUTION — мигает на сильных долях, XPDR — сколько осталось. Esc / «Посадка» — выйти.
- Не чаще 30 кадров/с, стоит, когда окно скрыто. Выключается в «Настройки → Остальное».

## Новое: вкладка «Остальное»
- Сюда переехали необязательные эффекты: тряска на басу, зеркало, вспышка на доле, хроматический сдвиг,
  тряска текста, контур неспетых слов, строки-плакат, клавиши W/X, анимация запуска, счётчик FPS. Сами настройки не изменились.

## Фон и игры
- Когда окно Pulse скрыто/свёрнуто (играет только виджет), приложение получает сигнал и перестаёт рисовать
  визуал, сцену текста, Mineradio и CSS-анимации; процессы окна и GPU получают пониженный приоритет.
- Виджет: «Тихий режим для игр» — через 4 с без мыши анимации останавливаются, время обновляется раз в секунду.

## Mineradio
- Исправлено: со временем клик по треку на 3D-полке не срабатывал (первый клик только прокручивал/закрывал список).
- Центральная карточка полки и следующий трек заранее подгружаются — музыка стартует быстрее.
