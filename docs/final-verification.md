# Финальная проверка Pulse 1.0.0

## Пройдено в Linux / Chromium
- 240 модульных и регрессионных тестов: `npm test`. Старые контрольные суммы и отчёты сохранены. Изменения текущего запроса отражены в отдельном `tests/final-approved.json`, не в исторических baseline-файлах.
- 280/280 проверок изменения изображения: 28 встроенных стилей × 10 общих эффектов, детерминированные входные данные. Сравниваются крайние значения настроек, не обещается одинаковый вид разных стилей. Плотность временного рельефа проверяется после накопления кадров.
- Украинский язык: >2000 строк, склонения, сложные HTML-подсказки настроек, сохранение пользовательского текста, нативные подписи. Автоаудит строк allTabs не нашёл непереведённых русских подсказок настроек.
- Реальный WebGL smoke для 3D-частиц и неонового круга: direct и совместимый copied path, без ошибок компиляции шейдеров.
- Ручка возврата: 1919, 1366 и 390 px, отсутствие пересечений с поиском, профилем и переключателем режима; закрытие без команды остановки звука.
- Sakura отсутствует в ресурсах и коде сцены; старое значение профиля использует orbit.
- Liquid Glass: backdrop-filter сохраняет SVG при прокрутке; reduced motion отключает переходы.
- 66 DOM-проверок кнопок/seek/volume виджета в трёх размерах и при изменённом масштабе, lock on/off. Это не нативный hit-test Windows.
- Полный сценарий файлового видео, pause/resume/seek, громкость, fullscreen, режимы, offline/conversion/stale load и адаптивные меню прошёл.
- Ранее в этой доработке прошёл `theme-widget-ui.cjs`: фоны, сохранение настроек, английский/японский виджет и семь экранов установщика.
- NSIS со штатной графикой компилируется; подтверждён код остановки дерева процессов и ожидания освобождения файлов.
- app.asar: новые модули входят в сборку, удалённые Sakura-ресурсы отсутствуют, проверены совпадения с рабочими исходниками.

- `npm audit --omit=dev`: 0 известных уязвимостей production-зависимостей на момент проверки. Это не полный аудит Electron/внешних бинарников и не гарантия отсутствия уязвимостей.

## Не проверено
- Реальная Windows-установка/обновление во время воспроизведения, освобождение блокировок старой версии и SMTC/Island Media Controls. Нужен пользовательский Windows-прогон.
- Реальные GPU, FPS и драйверы Windows; SwiftShader/Chromium не заменяет их.
- Пользовательское видео и ручная визуальная приёмка PNG: файловый помощник среды возвращал `computer_helper_failed`. Скриншоты созданы, DOM/геометрия проверены; утверждения о ручном просмотре не делаются.
- Полный независимый пентест и абсолютная защищённость. Проведён ограниченный анализ Rich Presence/IPC и публичного прокси изображений. Discord Application ID публичен, bot token/client secret в клиент не добавлялись.
- Сборки не имеют цифровой подписи разработчика. Не отключайте защиту Windows ради их запуска.

## Файлы проверки
`docs/final-checks/`: логи и JSON текущего прогона. PNG не включены в исходный архив, чтобы не раздувать его. Исторические документы описывают предыдущие состояния и не являются результатами этого прогона.
