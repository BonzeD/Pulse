# Локализация: исходники для подготовки публичного 1.0.0

Первоначально эти изменения были переданы как draft исходников. Теперь из них собраны новые portable и установщик; результаты — `docs/build-verification.md`. Старые, ранее выданные EXE этих изменений не содержат. Перед публичным Release необходимо проверить новые EXE в Windows.

## Изменения
- Дополнены английские и японские словари: настройки, редактор, DJ/MIDI, служебные сообщения, подсказки, раздел «О приложении».
- Динамические сообщения переводятся по шаблонам без перевода вставленных названий. Служебные счётчики переводятся отдельно от пользовательского контента.
- Проверено переключение EN → JA → RU → EN: счётчик меняет язык, название песни сохраняется.
- Авторы Pulse: Bon_zeD и Daswi. Claude, ChatGPT и Notion AI указаны отдельно как инструменты помощи; атрибуция сторонних компонентов сохранена.
- В README добавлено раскрытие использования ИИ. Инструкция публикации — `docs/github-publishing.md`.
- `renderer/viz.js`, `renderer/neon-gpu.js`, `renderer/gpu.js` совпадают побайтово с ранее переданными исходниками 1.0.0.

## Проверки
- `npm test`: 73 теста, 0 ошибок.
- `CHROMIUM_PATH=/usr/local/bin/chromium node tests/locale-sweep.cjs`: EN и JA; разделы настроек с обычными/инвертированными булевыми значениями, панели редактора и выбранные элементы, DJ/MIDI, справка, My Wave, основные страницы. Нет неожиданных русских надписей или ошибок JavaScript в проверенных сценариях.
- Русские названия тестовых песен «Тест переключения 1–5» в отчёте оставлены намеренно: это контент, не интерфейс.
- `CHROMIUM_PATH=/usr/local/bin/chromium node tests/chrome-ui.cjs`: сценарии интерфейса прошли.
- Вручную просмотрены скриншоты About и благодарностей на EN/JA, настроек на JA при 980×640 и DJ на JA. Дополнительно проверен независимый HTML-снимок About.

Логи и машинный отчёт приложены в `audit-evidence/localization-draft` (этот каталог исключён из Git). Они относятся к исходникам и браузерному тестовому окружению с подменёнными API, а не к установленной программе в Windows. Проверка отсутствия кириллицы не доказывает качество каждой японской формулировки. Сторонние плагины, реальные ответы сервисов и все возможные состояния аккаунтов этим прогоном не охвачены.

## Ожидает решения
Элемент на пользовательском скриншоте не выделен. Удаление двух предполагаемых кнопок визуализатора не выполнено до подтверждения, чтобы не удалить другую функцию.

Версия 1.0.0 сохранена по явному запросу автора для первого публичного выпуска. Не публикуйте эти исходники вместе со старыми EXE как соответствующий им код.
