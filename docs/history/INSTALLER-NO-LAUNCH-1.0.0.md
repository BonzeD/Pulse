# Pulse 1.0.0 — исправление установщика fix1

## Причина подтверждённого пользователем дефекта
Предыдущий Setup запускал установленный `Pulse.exe --quit-for-update` перед копированием файлов. Старые версии не знали аргумент и открывали приложение, даже если оно было выключено. `ExecWait` мог ждать закрытия такого приложения. Это ошибка сценария установщика, а не пользовательских действий.

## Исправление
Из секций установки и удаления полностью убран запуск установленного приложения. Windows taskkill обращается только к уже существующим процессам: сначала `/T`, затем `/T /F`, после чего остаётся ожидание освобождения файлов. Если Pulse выключен, запускать нечего и приложение не запускается. Единственная команда запуска Pulse остаётся в `FinClick`, по нажатию соответствующей кнопки после успешной установки.

Версия 1.0.0, графика и раскладка установщика, профиль, библиотека и runtime не менялись. Portable из предыдущей выдачи остаётся действительным. Предыдущие Setup и source заменены архивами с `fix1`, контрольные суммы обновлены.

## Проверки
- 242/242 теста: прежние 240 + запрет запуска в секции установки, запрет запуска при удалении и проверка единственного пользовательского запуска на экране завершения.
- Исторические baseline-хеши сохранены; изменён только отдельный манифест текущих разрешённых правок.
- Новый Setup компилируется из исправленного NSIS, после сборки проверяется совпадение payload с неизменным runtime.

Это Linux-сборка и статические/регрессионные проверки, не прогон установщика на настоящем Windows. Для приёмки нужны: установка при выключенном Pulse; обновление старой версии во время музыки; завершение без запуска; запуск новой версии только кнопкой на последнем экране.
