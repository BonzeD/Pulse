# Pulse 1.0.0 — откат графических изменений fix2

По запросу автора отменены изменения отрисовки, внесённые в fix2. Версия приложения остаётся 1.0.0. Это откат, а не новая оптимизация. GitHub-публикация не выполнялась.

## Что восстановлено
- renderer/app.js и renderer/viz.js восстановлены побайтно из сохранённого Pulse-1.0.0-source-fix1.zip. В app.js возвращён прежний кэшированный Canvas/PNG-фон; в Viz — прежнее поведение resize и reduced-motion.
- Фоновый модуль renderer/background-render.js и его подключение удалены. Удалён специфичный для отменённого Worker браузерный тест; вместо него в final-release добавлена проверка отката.
- Настройки FPS, качества, GPU, общих эффектов, Liquid Glass, тексты песен и MineRadio не менялись.

## Что сохранено из fix2
- Верхняя ручка возврата во вкладках «Песня», «Видео», «Визуал», без остановки музыки. На узком окне не перекрывает переключатель. У «Только текст» остаётся собственный выход.
- «Открыть в редакторе» в строке над предпросмотром, включая Discord.
- Исправления установщика: никогда не запускать установленный старый Pulse.exe для завершения; единственный запуск — явная кнопка после установки.
- Локализации, восстановление обложек плейлистов, «Моя волна», проверки Discord и удаление Sakura не откатывались.

## Верификация
Сравнение с двумя сохранёнными архивами выполнено автоматически: app.js/viz.js точно соответствуют fix1; installer.nsi/update-shutdown.nsh/motion.css/editor.js/studio.css/lystage.js/gpu.js точно соответствуют fix2. Отчёт: docs/rollback-checks/source-comparison.json.

Логи и сведения о содержимом пакета: docs/rollback-checks/. Предыдущие отчёты fix2 — история и не описывают текущую реализацию фона. Исторические контрольные суммы не изменялись.

## Ограничения перед релизом
Вернуть FPS 140 на компьютере пользователя здесь не подтверждено: требуется сравнение на том же Windows-ПК и с прежними настройками. Не выдавать сам факт отката или headless-тесты за устранение причины падения FPS. Проверить визуалы, «Только текст», переключение треков, установку с остановленным/играющим Pulse, SMTC/Island и нативные области перетаскивания. Сборки не подписаны; не отключать защиту Windows. В GitHub ничего не публиковалось.

Подтверждено для текущего отката: 245/245 unit/regression, 280/280 FX, полный UI smoke (локализация, ручка в трёх вкладках, 1919/1366/390 px, Discord action 100/125%, hover/camera, direct/copied GPU, Liquid Glass при прокрутке), full-app file-video. Выборочно вручную просмотрены PNG: ручка в Песне при 1919/390 px и кнопка редактора Discord при 1366 px; перекрытий в этих состояниях не обнаружено. Это не проверка реальных Windows FPS и не полный ручной прогон всех визуалов.

Portable собран electron-builder с compression=store, внешний ZIP deflate 6. Setup — исходный NSIS/LZMA. Источник и упакованный ASAR сверены: 188 файлов проекта, Worker отсутствует.
