# Pulse 1.0.0 — редактор Liquid Glass и Sakura glade

## Материал
Настройки → Внешний вид → Материал панелей и кнопок → Liquid Glass. Редактор доступен и в полном разделе настроек интерфейса.

- 13 добавляемых/убираемых эффектов: преломление, размытие, тонировка, цветокоррекция, световая кромка, Френель, дисперсия RGB, микрозерно, внешнее свечение, шёлковый блик, внутренняя/падающая тень и форма линзы.
- Числовые поля рядом с ползунками, мгновенное применение без пересоздания перетаскиваемого контрола. Сила/толщина/IOR; отдельные blur, opacity и brightness для плеера/меню/навигации; параметры бликов, теней и свечения.
- Отдельные области применения: плеер, меню, навигация, поиск, кнопки. Отключение возвращает обычное стекло; текст и SVG-иконки не искажаются.
- 7 встроенных вариантов: Оригинал, Subtle, Vivid, Vision, Обсидиан, Призма, Иней. Это веб-пресеты Pulse, не официальные пресеты Apple. Первые три названия вариантов вдохновлены открытой веб-реализацией: https://github.com/dpawlikowski/liquid-glass . Код оптики Pulse остаётся собственным.
- До 20 пользовательских вариантов: сохранение нового, загрузка, переименование, удаление; импорт/экспорт JSON до 64 КБ. Импорт ограничен белым списком ключей, цветов и диапазонов; произвольный CSS/JS не выполняется.
- `ui.glassFx` и `ui.glassPresets` внесены в схему, чтобы `mergeDeep` не отбрасывал сохранённые значения после перезапуска. Старые профили и авторский пресет сохраняют прежний вид.
- Системная уменьшенная прозрачность, forced colors и экономный режим имеют приоритет над оптическим материалом. Стекло перерисовывается по событиям, без постоянного RAF.
- Иконки кнопок транспорта выровнены по центру через grid/place-items, без изменения их действий.

## Сакуровая поляна
Только текст → Погружение → Мир → Сакуровая поляна.

- Третья сцена (`kWorld: sakura`, renderer world 3), не отдельный плеер/модальное окно. Орбитальная станция и Чёрное море сохранены.
- Восемь разветвлённых деревьев, инстансированные цветы, 24–100 тысяч травинок в зависимости от графики, летящие лепестки, тёплый направленный свет с тенями, мягкие световые лучи. Дальний пейзаж — локальная AI-generated matte painting; сетевые запросы для сцены не нужны.
- Полное освобождение инстансов и карт теней при переключении/выходе. Reduced motion убирает движение травы/цветов и летящие лепестки.
- Удалено принудительное ограничение до 10 кадров/с только из-за паузы. Частота теперь определяется настройкой fps, экономным режимом и reduced motion. Фоновое движение лепестков получает отдельное ambient-время, не поддельный аудиосигнал. Это исправление ограничения, не обещание 60 fps на любой видеокарте.

## Проверка
- 212 unit/regression tests: pass.
- Editor UI: seven built-in presets, live slider identity, remove/add retaining values, save/rename/import/reload, validation, scopes, eco/reduced transparency/forced colors, 1366×768 и 390×844, icon center, английский и японский: pass.
- Shared glass UI: switching/save/reload, actual backdrop displacement pixels, matching menu materials, local 8px gap, mobile, keyboard/scroll, bounded cache and no idle render loop: pass.
- Sakura standalone: desktop/mobile render, no JS/shader errors, WebGL error 0. Снимки созданы автоматически; ручной визуальный просмотр в среде недоступен из-за ошибки инструмента просмотра изображений, поэтому художественная визуальная оценка не заявляется.
- File-video UI: playback/pause/seek/shared volume, offline/audio-only/compatibility and menus: pass.
- Widget: 66 pointer/command checks across sizes/lock/scaling: pass.
- Основные `main.js`, `offline.js`, `media-tools.js`, `preload.js`, файловый видеоплеер, виджет и исходный `installer.nsi` побайтово сохранены относительно последнего исходного архива.
- Native Windows installation/runtime, физический GPU/FPS пользователя и живая загрузка YouTube в этой Linux-среде не проверены. Windows-сборки без подписи.

Версия остаётся 1.0.0; пересборка различается контрольными суммами, не номером версии.
