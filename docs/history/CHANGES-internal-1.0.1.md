# Pulse 1.0.1

- Удалён новый мини-трей / островок и весь порт Island Media Controls, включая его настройки, preload и исходник Windhawk.
- Обычный значок в трее и старый отдельный мини-виджет сохранены. Клик по значку открывает Pulse.
- Исправлены системные Play/Pause: повторный Play больше не означает Pause и наоборот. Добавлен seekto, синхронизируется playbackState, пустая очередь очищает медиаметаданные.
- Убраны запоздалые автопереключения и перемотки от предыдущего трека; ошибки resolver обрабатываются, индикатор загрузки снимается при отказе audio.play.
- Локальный сервер безопаснее обрабатывает пути и некорректные URL. Исправлены Range/HEAD для скачанного аудио и завершение оборванного потока.
- Добавлены проверки источника IPC и запрет ухода привилегированных окон на внешние страницы. Основная сессия больше не выдаёт произвольные разрешения.
- Библиотека записывается через временный файл с атомарной заменой и резервной копией. Отложенные изменения сохраняются при выгрузке окна. Запись аккаунтов/кэша сервисов тоже заменена на атомарную, без резервного хранения удалённых cookies.
- Electron обновлён с 37.10.3 до 44.8.0 из-за известных уязвимостей; применены совместимые обновления транзитивных зависимостей.
- Исправлен опасный uninstall: удаляются только файлы пакета, а не вся произвольная папка установки. UI не принимает корень диска.
- Исправлено зависание главного процесса на отрицательной длине Discord IPC frame, ограничен входной буфер.
- Подробный аудит, ограничения проверки и разбор Windhawk: AUDIT-1.0.1.md. Новая версия обязательна по AGENTS.md.
