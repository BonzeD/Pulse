# Pulse 1.0.0 — финальная доработка

## Изменения
- Sakura удалена из выбора миров, кода сцен и ресурсов. Старые настройки автоматически используют орбитальную станцию; библиотека и остальные настройки сохраняются.
- Обновление fix1: закрываются только уже существующие процессы Windows (`taskkill /T`, затем `/T /F`), без запуска установленного EXE; ожидается освобождение EXE, app.asar и SMTC-моста. Установщик/деинсталлятор остаются английскими с прежним оформлением. Заблокированные файлы не перезаписываются принудительно.
- Hover обложек: вход/выход света через opacity, мягкий tilt, общая позиция камеры больше не обнуляется при пересечении обложки.
- Фон: более высокое разрешение статического размытия, PNG, неподвижный слабый dither против полос в тёмных градиентах, ограниченный кэш. Это не покадровый шум.
- Украинский интерфейс: отдельный словарь более 2000 строк, склонения, настройки, виджет, tray, MineRadio и нативные подписи диалогов. Названия пользовательских треков, текст песен, имена файлов и исходные лицензии не переводятся. Внешние страницы входа принадлежат музыкальным сервисам.
- Дополнительные переходы элементов управления и меню; reduced motion и системная контрастность имеют приоритет.
- Liquid Glass сохраняет SVG-преломление при прокрутке. Экономный режим/ограничения платформы по-прежнему могут использовать обычное размытие.
- Эффекты: плотность, размер/толщина, свечение, бас, оттенок и общие zoom/shake/trails/flash/mirror подключены к встроенным визуалам. У 3D-частиц обложки исправлены размер/свечение/оттенок в GPU-пути. Пульс обложки действует только при видимой обложке; затемнение относится к фону.
- Верхняя ручка возврата из визуала: два шеврона и три горизонтальных штриха; закрывает большой экран, не останавливает музыку.
- Обложки плейлистов: сохраняются подписанные URL, выбирается наибольшая корректная миниатюра, восстановление отсутствующей картинки через данные плейлиста, ограниченная очередь и повтор после ошибки.
- «Моя волна»: разнообразные семена, исключение дублей записи/дизлайков/недавних треков, ограничения повторов артиста, строгий выбранный язык, таймауты источников, офлайн-повтор только после исчерпания доступных треков.

## Защита — область проверки
Discord Application ID — публичный идентификатор приложения, не bot token и не client secret. Клиенту эти секреты не нужны. Rich Presence теперь принимает ограниченные поля/длины и публичные HTTPS-ссылки; исправлено закрытие незавершённых IPC-подключений при отключении интеграции. Это проверка конкретной интеграции, не обещание абсолютной защищённости приложения.

Прокси обложек ограничен HTTPS-хостами изображений поддерживаемых сервисов. Каждый redirect проверяется заново; cookies не отправляются, есть таймаут, лимит 8 МиБ, блокировка SVG/активного содержимого и `nosniff`. Неуспешные ответы не кэшируются.

## Проверка и ограничения
Результаты конкретного прогона находятся в `docs/final-verification.md`. Исторические SHA-256 и отчёты не переписывались; разрешённые изменения зафиксированы отдельно.

Нужна проверка на реальном Windows: обновление во время музыки (включая старую сборку), SMTC/Island, нативные области перетаскивания, реальные GPU/60 FPS и воспроизведение защищённых сервисами треков. Сборки не подписаны. В этой среде нет Windows; воспроизведение пользовательского видео и ручной просмотр созданных PNG были недоступны из-за ошибки файлового помощника. DOM, геометрия и отрисовка тестируются программно; это не замена визуальной приёмке человеком.
