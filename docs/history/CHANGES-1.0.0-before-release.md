# Pulse 1.0.0 — panel2

Обновление интерфейса и общего аудиосигнала поверх stable-base. Версия приложения оставлена 1.0.0 по требованию пользователя; файлы отличаются суффиксом panel2 и контрольными суммами.

- Фоны основной области, бокового меню и раскрытого плеера растянуты до нижнего края во всех разделах, а не только на Главной. Сохранён обычный внешний зазор 8 px в каркасе «Панели».
- Полноразмерный фон отделён от защищённой области прокрутки. Прокрутка основной страницы и списка плейлистов заканчивается над плавающей панелью: видимые кнопки не проходят под ней. Вложенное меню настроек тоже ограничено по высоте. В раскрытом плеере элементы управления и содержимое правой колонки располагаются над ней.
- Громкость раскрывается внутри нижней панели рядом с кнопкой звука. Убраны отдельный попап и его нестабильная область наведения. Ползунок остаётся открыт при наведении и фокусе клавиатуры.
- Сама панель непрозрачна: текст прокручиваемого содержимого не просвечивает под кнопками.
- Визуализаторы теперь могут получать реальный спектр и при воспроизведении через встроенный YouTube. Ранее frame() и API MineRadio читали частоты только при engine === 'audio', а при fallback в YouTube сигнал отсутствовал.
- Добавлен независимый анализ captureStream() медиаэлемента внутри самого YouTube-фрейма. Он не перенаправляет, не выключает и не ставит на паузу оригинальный звук. Нулевая выходная громкость только у дополнительной аналитической копии, поэтому она не создаёт эхо. Микрофон и системный звук не захватываются.
- Данные принимаются только от текущего iframe #ytPlayer, разрешённых HTTPS-источников YouTube и с актуальным токеном. IPC доступен только главному фрейму окна Pulse. Старые данные не выдаются за живой сигнал.
- Один readSpectrum() передаёт реальные частоты в обычные визуалы, обновляет бас текстовых сцен и обслуживает PulseMR.freq/wave. При защищённом или недоступном captureStream сигнал не подменяется случайной анимацией. Поддержку конкретных YouTube-потоков нужно проверить на Windows.
- Загрузчик треков, выбор потоков, сетевые API, кэш и GPU-рендереры не переписывались. В main/preload добавлен только ограниченный IPC-канал анализа. Стабильный транспорт проверяется регрессионными тестами.

# Pulse 1.0.0 — стабильная база и новая панель

Основа — присланный пользователем исходник 2.0.12. Это откат предыдущей экспериментальной сборки, а не новая GPU-оптимизация. Номер 1.0.0 сохранён по ранее заданному требованию пользователя; архив и сборки следует отличать по SHA-256.

- Полностью возвращены исходные offline.js, services.js, main.js, preload.js, ytm.js и ytlist.js.
- Логика воспроизведения и fallback в renderer/app.js совпадает с исходной стабильной базой.
- Визуализаторы, GPU-модуль и текстовые сцены возвращены из стабильного архива. Предыдущие экспериментальные оптимизации удалены.
- Сохранён удачный фикс коллизии CSS-класса loading: кнопка плеера и «Моя волна» используют is-loading.
- Панель из «Только текст» адаптирована для основного окна: обложка/название, лайк, добавление в плейлист, меню, повтор, предыдущий/play/следующий, очередь, текст, громкость и раскрытие плеера.
- Основная панель не прячется автоматически; соответствующая настройка по-прежнему относится только к текстовой сцене.
- Вокруг панели зарезервировано место, чтобы она не закрывала содержимое. Изменение громкости раскрывает ползунок над панелью, а не сдвигает все кнопки.
- Для основной панели не используется backdrop-filter: без нового дорогостоящего размытия содержимого под ней. Старые эффекты сцен сохранены.
- Сохранены монохромные иконки. Геометрия SVG взята из стабильного архива; числовые координаты не менялись.
