# Промпт: редизайн интерфейса Pulse — красивее, понятнее, проще (без урезания механик)

> Задание для ИИ-агента (в первую очередь — для меня же в следующих сессиях). Работать поэтапно, каждый этап — рабочая сборка.
> Главное правило: **ни одна механика не пропадает**. Упрощаем то, как функции показаны, а не сами функции.

## Роль
Ты — продуктовый дизайнер и фронтенд-инженер десктопных музыкальных приложений (уровень Apple Music, Spotify, Яндекс Музыки).
Ты умеешь строить дизайн-систему, чистить многослойный CSS и переносить интерфейс по частям, не ломая пользователям настройки.

## Цель
1. **Красивее** — единый, спокойный, «дорогой» вид: одна сетка, одни отступы, одна типографика, один набор компонентов, мягкие анимации.
2. **Понятнее** — человек с первого взгляда понимает, где что: главное на виду, редкое — на шаг глубже, у каждой кнопки ясная подпись или подсказка.
3. **Проще** — меньше одновременно видимых элементов и настроек, меньше дублей, разумные пресеты вместо десятков ползунков.
4. **Без потерь** — каждая текущая функция, настройка, горячая клавиша, API плагинов и сохранённое значение пользователя продолжают работать.

## Что такое Pulse сейчас (проверь в исходниках, описанию не верь на слово)
- Electron-клиент музыки для Windows. Рендерер — один `renderer/index.html` + классические скрипты (общая глобальная область:
  функции переопределяются обёртками вида `{ const base = fn; fn = function () { … } }`) и 15 CSS-файлов, подключённых слоями:
  `style.css → pulse2 → pulse3 → settings → studio → clients → v203 → v204 → kara → gpu → refl → splash → anim → wave → spicy`.
  Поздние слои переопределяют ранние, местами через `!important` — это главный источник визуального шума и багов.
- Оболочка: левое меню `#side` (разделы + плейлисты `#sideList`), верхняя панель с поиском и входом, нижний плеер `#bar`,
  страница плеера `#pp` (режимы «Песня / Видео / Визуал», справа вкладки «Далее / Текст / Похожие», кнопки сдвига текста и корректора).
- Разделы: Главная, Обзор, Моя волна, Библиотека, Загрузки, Диджей, Настройки, а ещё страницы артиста, альбома, плейлиста и поиска.
- Клиенты: YouTube Music / Apple Music / Spotify (переключение меняет каталог и меню), аккаунты, вход через браузер.
- Текст песен: источники (все, YTM, Apple, Spotify, LRCLIB, Spicy Lyrics с ключом), караоке-движок `karaoke.js` (пружины и сплайны Spicy,
  слоги, буквы), стиль Spicy для всего текста, «Только текст» (`lystage.js`: отражение, частицы, градиенты) и Spicy-полноэкранный режим,
  корректор (`lyfix.js`: сдвиг, темп, запись по Пробелу, свой текст, поиск), автоподгонка сдвига, бэк-вокал, дуэты, цвета Spotify.
- Остальное: Моя волна (`wave.js`), визуализатор (`viz.js`, GPU), диджей (`dj.js`, `djctl.js`), мини-виджет (`widget.*`), музыкальные обои
  (`wallpaper.*`), Discord RPC, конфиги, плагины (`PLUGINS.md`, `Pulse.addSettingsTab`), горячие клавиши, редактор/кастомизация окна
  (`editor.js`, `customize.js`, регионы `CZ_REGIONS` — их селекторы использует сохранённая раскладка пользователя), темы, трей, заставка, установщик.
- Настройки: 19 вкладок (`allTabs()` в `app.js`), строки собираются из кирпичиков `R / grp / tg / seg / rng / sel / colr / xTxt`, поиск по ключам `k`.
  Значения — в `lib.settings` (умолчания `DEF_SETTINGS`, слияние `mergeDeep`).

## Жёсткие ограничения
- **Ничего не удалять из возможностей.** Можно прятать глубже («Ещё», «Дополнительно», раскрывающиеся группы), объединять дубли, заменять
  набор ползунков пресетом — но тонкая настройка должна оставаться доступной.
- **Не ломать сохранённое:** ключи `lib.settings` не переименовывать без миграции; если переносишь вкладку — перенаправь старый `lib.setTab`
  (пример: `spicy → ly`, `customize → editor`). Сохранённые раскладки редактора (`CZ_REGIONS`) и пользовательские темы должны работать.
- **Плагины и темы:** id элементов, классы-хуки (`.ly-line`, `.w`, `.cur`, `.past`, `#lyrics`, `#bar`, `#pp` и т. д.) и события `PX.on/emit` — это публичный API.
  Если меняешь — оставь старое имя рядом или опиши миграцию в `PLUGINS.md` / `CUSTOMIZE.md`.
- **Производительность не хуже:** режим «Экономно», `no-anim`, плавность текста (60 кадров), никаких новых постоянных `filter: blur` на больших слоях,
  анимации только `transform/opacity`, тяжёлое — только когда видно.
- Все тексты — по-русски, простыми словами. Комментарии к новому коду — с меткой версии (`// 2.0.x: …`). Правила версий — в `AGENTS.md`.

## Что сначала исследовать (аудит, до любых правок)
1. Снять скриншоты всех экранов и состояний (Playwright, `file:///…/renderer/index.html` с заглушкой `window.pulse`), включая пустые состояния,
   загрузку, ошибки, длинные названия, узкое окно (900 px) и широкое (2560 px).
2. Составить **карту функций**: каждая кнопка, меню, клавиша, настройка → где она сейчас и куда переедет. Это контрольный список «без потерь».
3. Найти дубли и конфликты: похожие настройки в разных местах (например, «Размывать дальние строки» в «Текст песен» и в блоке Spicy, несколько режимов
   «Только текст», свечение текста в нескольких слоях), одинаковые действия с разными подписями, разные стили одних компонентов.
4. Посчитать CSS: какие правила перебиваются позже, где `!important`, какие селекторы мёртвые.

## Направление дизайна
- **Дизайн-токены** в одном месте (`renderer/ds.css`): цвета (фон, поверхности 1–3, текст 1–3, акцент из обложки), радиусы, тени, отступы (шаг 4 px),
  размеры шрифта (5–6 ступеней), длительности и кривые анимаций. Все экраны берут значения только отсюда.
- **Компоненты** с одним видом везде: кнопка (основная, второстепенная, иконка), переключатель, сегменты, ползунок, поле, меню, всплывашка,
  модальное окно, карточка трека/альбома/артиста, строка трека, полка с прокруткой, вкладки, тост, пустое состояние, скелетон загрузки.
- **Прогрессивное раскрытие:** в настройках у каждой вкладки сверху 3–6 главных пунктов, остальное — в группе «Дополнительно» (свёрнута).
  Переключатель «Простые / Все настройки» глобально. Пресеты (например, для текста: «Классика», «Spicy», «Караоке», «Минимум»), которые выставляют
  набор значений, но не запрещают потом подкрутить.
- **Настройки по месту:** у текста, визуализатора, волны, виджета — маленькая кнопка ⚙ рядом, открывающая всплывашку с главными параметрами
  и ссылкой «Все настройки…». Вкладки настроек сгруппировать (Основное / Оформление / Музыка / Окна и интеграции / Дополнительно) и сократить
  их число, объединив близкие (например, «Интерфейс» + «Внешний вид», «Редактор» + «Кастомизация» уже объединены — продолжить).
- **Командная палитра** (Ctrl+K): поиск по разделам, действиям и настройкам — использует уже существующие ключи поиска настроек.
- **Плеер:** нижняя панель — только главное (обложка, название, ▶, ⏮ ⏭, прогресс, громкость, лайк); редкое — в меню «⋯».
  Страница плеера: крупная обложка/видео/визуал, текст — красивый по умолчанию (стиль Spicy как пресет), меньше кнопок на виду.
- **Главная и Моя волна:** ясная иерархия (одна большая карточка «продолжить / волна», дальше полки), одинаковые карточки, без перегруза подписями.
- **Анимации:** одна система переходов (уже есть `pageLeave`/fade) — привести к токенам, уважать `no-anim` и «Экономно».
- **Доступность:** контраст не ниже 4.5:1 для текста, видимый фокус для клавиатуры, подсказки `title` у иконок, размер целей ≥ 32 px.

## Как работать (этапы, каждый — отдельная сборка)
1. Аудит + карта функций + скриншоты «до» → `docs/ui-audit.md`.
2. Дизайн-документ: токены, компоненты, макеты ключевых экранов (можно HTML-макетом в `docs/mock/`), список изменений по экранам.
3. Токены и компоненты (`ds.css`, без смены вида экранов) → затем по одному экрану: оболочка → плеер → текст → главная/волна → библиотека/страницы → настройки → окна (виджет, модалки).
4. После каждого экрана — удалить перебитые старые правила из слоёв `pulse2/pulse3/v203/v204…` (чистка, а не ещё один слой поверх).
5. Миграции настроек и `lib.setTab`, обновить `PLUGINS.md` / `CUSTOMIZE.md`, `CHANGES-<версия>.md` простыми словами.

## Проверка перед сдачей каждого этапа
- `node --check` для всех JS; headless-прогон без ошибок в консоли; скриншоты «после» тех же экранов.
- Пройти карту функций: каждая функция достижима (не больше 2 кликов для частых, не больше 3 для редких) и работает.
- Старые настройки пользователя открываются без сбросов; темы, раскладки редактора и плагины выглядят нормально.
- Режим «Экономно» и `no-anim` — без тяжёлых эффектов; текст песни идёт плавно.
- `npm run dist` проходит, установщик и portable собираются.

## Практические заметки для меня
- Рабочая папка песочницы может очищаться между сообщениями: исходники восстанавливать из последнего архива `Pulse-<версия>-source.zip`
  (`unzip` в `/data/pulse`, затем `npm ci --no-audit --no-fund`). Сборка `npm run dist` идёт ~15 минут — запускать в фоне и ждать.
- Тест интерфейса: Playwright + системный Chromium, заглушка `window.pulse` — рекурсивный Proxy (иначе часть модулей падает при запуске).
- Пользователь пишет по-русски и хочет коротко: что сделано, что проверено, что нет. Файлы — установщик, portable, архив исходников.
