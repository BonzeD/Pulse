# Проверка переорганизации Pulse 1.0.0

- Все 615 файлов предыдущего исходного архива сохранены; карта — docs/manifests/REORGANIZATION-MAP.json.
- 607 файлов перенесены без изменения байтов. Изменены только 8 существующих служебных/документационных файлов: .gitignore, AGENTS.md, GitHub Actions, FOR AI, инструкция публикации, архиватор и два пути чтения документации в тестах.
- Runtime JavaScript, renderer, локализации, CSS виджета, установщик, нативный код, исходные app/package.json и app/package-lock.json не изменены.
- Исторические отчёты и baseline-файлы сохранены. Новые README, npm-обёртка, проверка структуры и инструкции добавлены отдельно.
- npm ci из нового корня успешно установил зависимости в app/node_modules.
- npm test из нового корня: 261 тест прошёл, 0 ошибок; 1 тест сгенерированной графики установщика пропущен, поскольку исходный архив не включает результаты сборки. Дополнительная проверка структуры прошла.
- npm run test:widget-clicks из нового корня: 97 Chromium-проверок прошли, ошибок страницы нет. Нативное Windows-перетаскивание этим тестом не проверяется.
- Локальные ссылки текущих README, AGENTS, инструкции структуры и публикации проверены.
- Артефакты npm, dist, временные файлы и .env исключаются из исходного ZIP; вложенная base_library.zip yt-dlp сохраняется.

Полная Windows-пересборка в этой доработке не выполнялась. Ранее подготовленные EXE с исправлением виджета остаются применимыми: изменилась раскладка исходного репозитория, а не runtime. GitHub Actions обновлён для app/, но запуск job на GitHub здесь не выполнялся.

При установке зависимости приложения по-прежнему сообщают о 8 предупреждениях умеренного уровня; корневая обёртка без зависимостей может отдельно показывать 0. Это не означает устранение предупреждений приложения.
