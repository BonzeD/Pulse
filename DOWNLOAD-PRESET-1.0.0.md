# Дополнение Pulse 1.0.0: загрузчик, ссылки и основной пресет

## Ошибка запуска Python при скачивании

В исходном комплекте `resources/yt-dlp` отсутствовал `_internal/base_library.zip` — стандартная библиотека PyInstaller, включая `encodings`. Исполняемый файл и `python310.dll` были на месте, но одного EXE недостаточно. Это согласуется с сообщением `[PYI-6348:ERROR] Failed to start embedded python interpreter!`. Реальный запуск на ПК друга в этой среде не воспроизводился.

Восстановлен **полный официальный `yt-dlp_win.zip` версии 2026.08.19**. Архив проверен по SHA-256 из официального `SHA2-256SUMS`; источник и хеш сохранены в `resources/yt-dlp/provenance.json`. Компоненты и лицензии не отфильтровываются по расширению. `build/source-archive.py` специально сохраняет вложенные ZIP, в том числе `base_library.zip`.

Дополнительные меры:
- неполный кэш обновления пропускается в пользу полноценной встроенной копии;
- выбор Windows-копии включает запуск `--version`, а не только проверку наличия EXE;
- обновление проверяет официальный SHA-256, полноту распаковки и `--version` до активации;
- ошибка обновления не помечается как успешное обновление;
- замена каталога не происходит, пока загрузчик используется;
- наследуемые `PYTHONHOME`, `PYTHONPATH`, `PYTHONUSERBASE` и подобные переопределения не ломают встроенный интерпретатор;
- пути с апострофами безопасно передаются PowerShell;
- `afterPack` прерывает сборку, если ресурсы Python потеряны.

Ни повышение прав, ни отключение защит Windows не требуются для исправления неполного комплекта. Если система отдельно блокирует корректный файл, нужна диагностика события в журнале защиты, а не отключение защиты.

## Копирование ссылок

Запись перенесена из `navigator.clipboard` в `Electron.clipboard` через ограниченный IPC главного окна. Проверяются тип и размер текста. Виджет и внешние страницы не могут вызвать этот IPC. Пункты меню трека, плейлиста и копирование LRC используют единый обработчик. Сообщение об успехе появляется только после успешного ответа; ошибка сервиса или буфера показывается явно.

## Настройки и авторский пресет

Текущая установленная сборка использует `%APPDATA%\Pulse\library.json`, настройки — `library.settings`. Часть состояния Майнрадио хранится отдельно в Chromium Local Storage. Не следует пересылать весь каталог профиля: там могут находиться данные аккаунтов.

Для передачи оформления: **Настройки → Основные → Настройки в файл → Экспорт**. В простом режиме группа может находиться в раскрываемом блоке «Дополнительно». Результат — `pulse-settings.json`. Новый экспорт не содержит ключ `settings.spicy.key`, cue-точки треков, библиотеку и аккаунты; действующий ключ в приложении не изменяется. В старом экспорте ключ нужно очистить вручную перед отправкой.

**Авторский файл ещё не получен.** Внизу основных настроек добавлен явно неактивный пункт «Основной пресет» с объяснением ожидания. Никакой случайный набор вместо авторского не применяется, текущие пользовательские настройки и заводские значения не перезаписаны. Активация кнопки и установка авторского набора при первой установке — следующий шаг после получения и проверки файла. Настройки внутри самого Майнрадио требуют отдельного уточнения охвата.

## Проверки и ограничения

- 123/123 Node-теста: прежние регрессии, реальные импорт/экспорт аудио, теги/обложки, неполный кэш загрузчика, probe и очистка окружения, успешное/неуспешное копирование и приватность экспорта.
- 10 UI-сценариев локальной библиотеки и редактора; 5 UI-сценариев новых исправлений, включая реальные клики меню с недоступным browser clipboard.
- Общие настройки проверяются на поддерживаемой минимальной ширине окна **980 px** и на 1366 px. Редактор метаданных отдельно проверен и на 390 px.
- Прежний сценарий `tests/mr-ui.cjs` останавливается на несовпадении регистра локализованной подписи (`Now playing` вместо исторического `NOW PLAYING`); это не ошибка клика. Специализированные тесты восстановления панели Майнрадио, затухания и анимации запускаются отдельно.
- Реальная установка Windows, UAC, системный Windows clipboard и скачивание с аккаунтом друга требуют проверки на Windows. Попытка запустить нативный Linux Electron-стенд в этой среде остановилась из-за отсутствующей `libgtk-3.so.0`; она не засчитана как пройденный тест. Node-тесты и UI-тесты не заменяют проверку Windows.
