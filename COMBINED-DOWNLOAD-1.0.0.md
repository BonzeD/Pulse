# Pulse 1.0.0 — звук и видео в одном файле

Этот выпуск заменяет прежнее поведение загрузки раздельных аудио/видеофайлов. Номер версии и исходный установщик не меняются.

## Скачать → Вместе с видео
- Итоговый файл — `<YouTube ID>.video.mp4` с настоящими аудио- и видеодорожкой. Отдельный аудиофайл для той же загрузки не остаётся.
- yt-dlp загружает дорожки в служебную временную папку; FFmpeg явно объединяет видео и звук. H.264/AAC по возможности копируются без перекодирования; другие кодеки приводятся к H.264/AAC.
- Готовый MP4 проверяется повторно через ffprobe на наличие обеих дорожек, затем публикуется. Только после успешной публикации удаляются старые отдельные медиафайлы того же ID из папки офлайн-загрузок. Обложка и метаданные остаются.
- При сбое объединения или отсутствии звука старые файлы не удаляются; такой результат не отмечается как успешная загрузка «вместе с видео».
- Уже скачанные раздельные дорожки одного ID объединяются при открытии видео, без интернета. Если дорожки принадлежат разным ID, они не объединяются по похожему названию: это могут быть разные записи.
- Алиасы одной загрузки из разных сервисов показываются одной записью в «Скачанном». Разные исходные записи с одинаковым названием не склеиваются.

## Меню над плеером
- «Доп. действия» и вложенные меню заканчиваются выше видимой панели плеера с зазором 24 px, учитывающим выступающую кнопку скрытия.
- При нехватке места меню поднимается и ограничивает высоту с прокруткой, не перекрывая управление воспроизведением.
- Когда панель скрыта, меню может использовать свободную высоту окна.
- Обновлены подписи «Только аудио» / «Вместе с видео» и правила FOR AI.md.

## Проверки именно этого исправления
- `npm test`: 201 / 201.
- Два реальных отдельных потока (без звука MP4 + M4A) после имитации выхода yt-dlp объединяются настоящим FFmpeg. В папке остаётся один MP4; ffprobe видит H.264 и AAC, декодируется видеокадр, уровень звука после декодирования не равен тишине.
- Ремонт старой раздельной загрузки работает без сети и сохраняется после повторного создания каталога.
- Audio-only, video-only без доступного аудио, сбой mux и фиктивный zero-exit результат без звука не считаются успешными. Старые файлы проверяются по хешам на сохранность при неудаче.
- `node tests/file-video-ui.cjs`: объединённый из отдельных дорожек файл воспроизводится в офлайн-сценарии с проверкой ненулевого сигнала в общем аудиографе. Сеть браузера отключена; доступны только локальные файлы тестового сервера.
- Геометрические UI-проверки и просмотр снимков 1366×768 и 390×844: основное и вложенное меню не перекрывают плеер.
- Живое скачивание с YouTube, установка и native hit testing в Windows в этой Linux-среде не запускались. Сборки не подписаны.
