# Canvas 2D и появление мини-виджета — 1.0.1

## Изменения
- Девять тяжёлых Canvas-пресетов (Кольцо, Эквалайзер, Частицы, Гиперпрыжок, Соты, Пламя, Созвездие, Пластинка, Лучи) больше не выполняют стандартный shadowBlur для каждого примитива. Геометрия рисуется в переиспользуемый слой в полном выбранном DPR; мягкое свечение строится один раз из отдельной маски половинного размера. Это не пиксельно идентичный blur при пересечениях, но плотность, цвета, движение и резкость геометрии не урезаются. Размеры слоёв меняются только при реальном изменении размеров холста; destroy освобождает ссылки. GPU-пресеты и явные индивидуальные glow-проходы остальных стилей не изменены.
- «Созвездие»: точная проверка расстояния выполняется только в соседних ячейках пространственной сетки. Сетка обновляется после движения и изменения басового радиуса. Связи не ограничиваются, порядок отрисовки сохранён. В детерминированной сцене: 90 точек, 273 связи, 657 кандидатов вместо 4005 пар.
- Ядро/чёткая геометрия всех девяти стилей при glow=0 совпадают с предыдущей сборкой попиксельно. При включённом свете проверены настройки glow/density/thick/bass/hue/zoom/shake/trails/flash/mirror; 280 из 280 дают изменение изображения. Для additive-пресетов сохраняется lighter при наложении на шлейф.
- Виджет: запрос показа переживает первоначальную загрузку и выполняется после did-finish-load с актуальными state/config/lyrics/visibility. Возврат в главное окно отменяет ожидающий запрос. Поздний focus скрытого/свёрнутого главного окна больше не прячет виджет. Уничтоженное окно пересоздаётся при следующем показе; позиция заново проверяется относительно подключённых мониторов. onTop/autoHide/onMin, прозрачность, закрепление, клики и preview сохранены.
- Workflow включает Linux FFmpeg до тестов и проверку структуры после dist: generated media-bridge notices проверяются после генерации, а не до неё.

## Проверки
Команды запускались из `app/`. Итог: 360 unit-тестов прошли, 0 ошибок; 1 проверка сгенерированных картинок установщика пропущена (дизайн/сценарий не менялись, Setup в этой быстрой тестовой пересборке не собирается). 97 UI-проверок виджета прошли; 280/280 комбинаций эффектов прошли. Новые Canvas UI и старые переходы Canvas/GPU прошли.
- npm test (включает 7 новых сценариев widget-lifecycle).
- npm run test:canvas-perf — геометрия, число точек, связи, эффекты, снимки; без WebGL, quality=high.
- npm run test:visual-performance — Canvas/GPU/empty переходы, отсутствие лишней очистки direct canvas, неизменный resize.
- npm run test:final-effects — 280 комбинаций.
- npm run test:widget-clicks — DOM-клики, 3 размера, lock, масштаб, анимации.
- node tests/canvas-profile.cjs — диагностическая принудительная растеризация. VIZ_BASELINE=1 сравнивает с точной обратной версией до hotfix. Эти числа не являются Windows FPS: getImageData и программная графика меняют профиль нагрузки.

Исторические контрольные суммы не изменены. canvas-perf-approved.json содержит отдельную точную обратную правку для старых baseline-проверок, новое поведение проверяется без её применения. Версия остаётся 1.0.1, GitHub не опубликован. Для локальной упаковки переиспользован неизменный медиамост из предыдущего проверенного Setup (SHA256 ec975af9f1ce147257ea7bb071f9f42fb61334d574e27369c2977977c38398e8); native исходники не менялись. CI по-прежнему собирает медиамост через .NET 8.

## Что ещё проверить на Windows
Одинаковые трек/позиция, размер окна, DPR, качество и лимит FPS до/после; Созвездие/Соты/Пламя с музыкой и без, glow=0/100/200, шлейфы/зеркало, другие пресеты. Проверить аппаратное ускорение в обоих режимах, не менять сохранённый профиль ради сравнения. Проверить многократное закрытие/открытие, раннее закрытие, onMin, tray/quit, отключение второго монитора и настоящий native hit-testing. Стабильные 60/120 FPS и устранение всех причин исчезновения виджета на Windows не подтверждены локальными Linux-тестами.
