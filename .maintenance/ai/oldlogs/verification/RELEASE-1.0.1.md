# Pulse 1.0.1 — тестовая сборка, без публикации

## Запрошенные исправления

### Настройка графики
- `perf.gpu` выбирает WebGL для поддерживаемых визуалов и частиц. Это **не** глобальное отключение аппаратного ускорения Chromium, CSS-композиции или ускорения Canvas.
- Одинаковый FPS при переключении, особенно у Canvas-пресетов вроде обычного кольца, сам по себе не доказывает ошибку настройки.
- Исправлен реальный дефект: canvas частиц запоминал первый контекст и не переключался между WebGL и Canvas при изменении настройки. Теперь canvas заменяется только при переходе, старый контекст освобождается, частицы/настройки сохраняются. При потере WebGL — устойчивый Canvas fallback без постоянных повторных попыток.
- «Погружение» останавливает и освобождает сцену при выключении настройки и снова создаёт её при включении. Статус `gpuOn` учитывает выключенный переключатель.
- Прежняя оптимизация frame pacing сохранена. Пользовательские FPS/качество не снижались; lyric timing, звук и MineRadio не переписывались.

### Имя Apple Music
- Вместо синтетической подписи `Apple ID · <страна>` запрашивается собственный профиль `/v1/me/social/profile`.
- Поддержаны JSON API и resource-map представления. Не используются имена чужих профилей, артистов или подписчиков.
- Имя не зашито в код. Кэш привязан к хэшу токена, ответы во время переключения аккаунта отбрасываются. Ручные названия и ранее полученные настоящие имена не стираются при временной ошибке.
- Уже сохранённый аккаунт обновляется при первом запросе статуса, без прежнего ожидания десяти минут.
- Если Apple не предоставляет социальный профиль/имя, резервная подпись — `Apple Music`. Получение именно `Bon zeD` на аккаунте автора ещё требует пользовательской проверки; реальный аккаунт не использовался в тестах.

### Локализация главной
- Просмотрены кадры приложенного видео: японская навигация сочеталась с русскими/английскими полками и категориями у YouTube Music, Apple Music, Spotify.
- UI-язык передаётся главному процессу при старте и изменении. YouTube получает `hl` и Accept-Language, Spotify — языковой заголовок и locale для соответствующих операций, Apple — параметр `l` для каталога/рекомендаций.
- Страна аккаунта/storefront не подменяется. Если язык не поддержан storefront Apple, запрос один раз повторяется без нового `l`; известные служебные заголовки переводятся в renderer.
- Кэш страниц разделён по языкам; старый асинхронный ответ не загрязняет новый языковой кэш. Синхронизация языка завершается до следующего запроса каталога.
- Добавлены переводы наблюдавшихся полок/категорий и безопасная обработка шаблонов с именами для ru/en/ja/uk. Карточки музыки, пользовательские плейлисты, имена и тексты песен не переводятся. Служебная подпись локальных файлов переводится отдельно от пользовательских названий.
- Неизвестные заголовки, которые сервис добавит в будущем и вернёт на другом языке вопреки параметрам запроса, не переводятся эвристически как произвольный пользовательский контент.

### Точный таймкод для создания текста
- Нажатие на время плеера переключает обычный формат и `00:06.53`; повторное нажатие возвращает обычный вид. Работают Enter и пробел.
- Сотые берутся из существующей позиции воспроизведения, без округления вверх и без изменения позиции/паузы/очереди. Точность самого источника (особенно YouTube) остаётся ограничением: это не обещание sample-accurate тайминга.
- Точный режим также используется в подсказке перемотки. Выбор сохраняется локально. Для длинных записей показываются часы.
- Отдельный RAF/таймер не добавлен: при включённом точном режиме время обновляется в существующем RAF с ограничением около 60 обновлений/с; обычный режим остаётся на прежних 250 мс.

### Версия и правила
- По прямой просьбе автора: 1.0.1 в package/lock, API/host, установщике и его графике.
- AGENTS.md и FOR AI.md: повышение версии только по явной просьбе автора, без автоматического повышения при исправлениях.
- Имена исходного архива формируются из package version. Дизайн и сценарии установщика сохранены. В команде сборки явно указан `--publish never`.
- Исторические baseline/отчёты не переписаны. `tests/release-101-approved.json` содержит точные обратные патчи перед прежними историческими адаптерами; новое поведение проверяется отдельно.

## Проверки
- `npm test` — unit/regression + целостность структуры репозитория.
- `npm run test:timecode` — клик/Enter/пробел, переходы секунд/минут, главный/раскрытый/lyrics-плеер, сохранение режима, отсутствие перемотки и Play/Pause.
- `npm run test:release-101` — настоящий Chromium: 3 сервиса × 4 языка, 17 заголовков и 9 категорий; сохранность метаданных; 1366×768 и 390×844; реальные WebGL ↔ Canvas переходы и восстановление «Погружения».
- `npm run test:visual-performance` — 28 Canvas-пресетов пиксельно совпадают с прежним алгоритмом; direct WebGL не очищает скрытый Canvas каждый кадр, переходы и resize сохранены.
- `npm run test:final-effects` — все 280 проверок влияния параметров дают различие изображения.
- `npm run test:final-ui` — украинские настройки, выход из визуалов, шейдерные пути, непрерывность камеры, reduced motion, Liquid Glass и отсутствие Sakura.
- Содержимое ASAR сверяется с исходниками; проверяются PE-версии, нативный медиамост, Python runtime yt-dlp и архивы выпуска.

Публичный Apple-каталог storefront `ua` отдельно ответил HTTP 200 на запросы `ja-JP`, `en-US`, `uk-UA`, `ru-RU`. Проверка выполнена без пользовательского входа; это не проверка персональных рекомендаций или профиля.

## Что не проверено
**Здесь использовались Linux и Chromium/SwiftShader.** Это не проверка установки/обновления/SMTC на Windows, не замер FPS на видеокарте автора и не подтверждение стабильных 120 FPS. Не проводился вход в личные аккаунты. Перед публикацией нужны Windows smoke/обновление поверх текущей версии, реальный FPS и проверка имени/рекомендаций на аккаунтах автора.
