# Atlas celestial sphere — Pulse 1.0.3

The existing `lib.atlasCosmos` version-1 data and playback path remain compatible. Its coordinates are now projected onto a celestial sphere; dragging empty sky changes yaw/pitch, while dragging a star or Shift-dragging its group continues to edit stored positions. Arrow keys on the focused sky rotate the view. The sky image uses modest parallax, not a true volumetric model. Camera orientation is temporary; authored star and constellation positions remain local. A quiet occasional meteor is decorative and respects reduced-motion/no-animation.

The playlist chooser merges local Pulse playlists with the current service's sidebar playlists (YouTube Music, Apple Music, Spotify). Local entries remain linked; service entries are loaded through the existing browse path and save a track snapshot. Service list loading may require a signed-in account and network access. Errors and empty playlists do not create stars. The ordinary and local track context menus both offer adding a star to open space or connecting it to an existing group. A group attachment adds an edge automatically; the connected-graph checks remain in force. Settings and song details now open in an overlay; the compact scene uses cross-shaped star rays.

Verification: `tests/atlas.cjs` covers the graph invariants and audio rollback. `tests/atlas-ui.cjs` covers persistence, editing, playback delegation, touch-sized layouts and reduced motion. `tests/atlas-sphere-ui.cjs` uses mocked service and IPC responses to exercise all three service list choices, loading/error handling, both track menus, group attachment, panoramic pointer and keyboard controls, and overlay bounds on mobile. These are not tests of real accounts, live services, audio or Windows execution.
