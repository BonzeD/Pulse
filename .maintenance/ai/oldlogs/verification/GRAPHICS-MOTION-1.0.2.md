# Pulse 1.0.2 — аудит 2D и анимации панелей

## Область проверки

Проверены renderer/viz.js (28 встроенных стилей), основной цикл в app.js, FFT/огибающие, полноразмерный sharp-слой и bloom, прямой/копируемый WebGL fallback, геометрия/ResizeObserver, экземпляры превью в extras.js, корректор lyfix.js, всплывающие панели custom.js и общий surface-motion.js. MineRadio и отдельный 3D/Immersion renderer не переписывались.

## Найдено и исправлено

| Проблема | Исправление | Проверка |

## Что сохранено

Не снижен лимит FPS, density, число связей/частиц, выбранный DPR резкой геометрии или частота аудио. Прежний grouped bloom девяти стилей, additive fire/rays, индивидуальное свечение остальных, trails/flash/mirror, прямой GPU и fallback сохранены. Не возвращались экспериментальные GPU-флаги и фоновый Worker. Исторические manifests/отчёты не переписаны: graphics-102-approved.json — отдельные точные обратные изменения.

## Проверки

- npm test после генерации арта: 365 тестов, 365 прошли, 0 ошибок, 0 пропусков; проверены все DPI установщика 1.0.2.
- tests/graphics-102-ui.cjs: sharp pixel equality для 28/28 стилей, 6388 конечных Canvas-координат, short waveform/zero-height, реальное освобождение WebGL2.
- tests/canvas-perf-ui.cjs: прежние проверки grouped glow, полной резкости, движения звёзд, точных связей и FX прошли.
- tests/visual-performance.cjs: 28 Canvas-пресетов, direct/copied/fallback и последовательные переключения режимов прошли.
- tests/final-effects.cjs: все 280 пар preset×effect дают изменение изображения.
- tests/final-ui-smoke.cjs: прежние UI/шейдерные/эффектные/reduced-motion проверки прошли.
- tests/kinetic-motion-ui.cjs и tests/lyric-studio-ui.cjs прошли. Старый dialog-mid тест зависел от задержки 70ms под нагрузкой упаковщика; теперь реальные существующие CSS-переходы ставятся на паузу в промежуточной точке, с обязательной проверкой наличия анимации. Ожидание завершения resize перед меню увеличено; проверки функциональности и исторические hashes не ослаблены.
- tests/panels-102-ui.cjs: 30 проверок, 0 page errors. PNG корректора и popup просмотрены отдельно в desktop/узком окне. Узкая проверка использует существующий sidecar-режим; это не Android-сборка.

## Ограничения и дальнейший замер на Windows

Linux Chromium/SwiftShader и детерминированная растеризация НЕ подтверждают стабильные 144 FPS на видеокарте пользователя. CPU submit 0.8ms тоже не измеряет полное время GPU-композиции. Сохраняется стоимость прозрачных полноэкранных слоёв, bloom, backdrop-filter и сложных пользовательских комбинаций эффектов. Не отключать их молча ради красивого счётчика.

Для сравнения запускать 1.0.1 и 1.0.2 по очереди на одном треке/окне/мониторе, с одинаковыми FPS, графикой, glow/density/blur; 30 секунд прогрева, затем 60 секунд записи frame time. Отдельно проверить звёзды, bars/particles/fire, переключение вкладок/панелей и уход с вкладки настройки. Записать медиану/p95/p99 времени кадра и missed frames через DevTools Performance, а не только FPS в оверлее. Проверить 20 быстрых открытий/закрытий, выключение анимаций, масштаб Windows 100/125/150%, мини-виджет и обновление играющего приложения.

Windows portable/Setup собираются на Linux; нативная установка, SMTC и реальный GPU здесь не запускались. Существующий неизменённый media bridge переиспользован, не пересобран без .NET SDK. GitHub/release не опубликованы.
