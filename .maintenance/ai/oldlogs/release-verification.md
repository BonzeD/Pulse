# Историческая проверка Pulse 1.0.0 (до дополнения локализации)

Актуальная проверка новых EXE: `docs/build-verification.md`. Ниже сохранён отчёт предыдущей сборки.

Этот выпуск основан на проверенной внутренней 1.0.1, а не на старой 1.0.0. Номер изменён по явному запросу автора. Изменения безопасности прежнего аудита сохранены.

## Выполнено

- `npm ci` по lock-файлу и компиляция self-contained Windows x64 SMTC-helper против Windows SDK.
- `npm test`: **69 pass / 0 fail / 0 skipped**. Включает протокол нового helper, ограничение размеров/backpressure, allowlist команд, передачу состояния в главном процессе, реальные Play/Pause/seek обработчики renderer, прежние security/regression tests.
- `tests/chrome-ui.cjs`: Full/Clean × обычный/облегчённый режим, прокрученные настройки, экран визуализации, ширина 980; прозрачная шапка, область скролла ниже неё, отсутствие второй прямоугольной обложки, наложений вкладок и Fullscreen/Lyrics, отсутствие просвечивания настроек. Скриншоты просмотрены.
- `tests/ui.cjs`: основные маршруты, геометрия нижней панели, громкость, безопасная область последних кнопок, ширины 1366/980/390, переход в текстовый режим и обратно; page errors отсутствуют. Независимый HTML capture просмотрен.
- `tests/audio-signal.cjs`: реальный sine signal → local AudioContext и cross-origin capture → bass/FFT/визуал/MineRadio. Это не тест Windows-аудиодрайверов.
- GPU-файлы `renderer/viz.js`, `renderer/neon-gpu.js`, `renderer/gpu.js` совпадают с предыдущими исходниками: успешная оптимизация не откатывалась.
- Упакованный app.asar: **123 файла** совпадают с рабочими исходниками, версия package/PE — **1.0.0**; новый мини-трей отсутствует; отдельный native helper совпадает с результатом компиляции.

- Обе конечные EXE прошли проверку целостности 7-Zip. Из portable (вложенный `app-64.7z`) и установщика извлечены app.asar и SMTC-helper: SHA-256 совпадают с проверенным unpacked-пакетом. Экран установщика с номером 1.0.0 просмотрен. Это проверка упаковки, не запуска установки в Windows.

Контрольные суммы и логи находятся в `audit-evidence/release-1.0.0` в переданном архиве; каталог исключён из Git, чтобы не засорять публичный репозиторий. Исторические логи предыдущего аудита не выдаются за тесты текущего выпуска.

## Что обязательно проверить до публичного релиза

Windows WinRT/GSMTC и внешний Windhawk здесь **не запускались**. Реальное появление сессии, работа кнопок/перемотки на Windows, установка/удаление и цифровая подпись не подтверждены. Следовать `docs/windows-media-session.md`; не объявлять совместимость подтверждённой лишь по успешной компиляции.

GitHub workflow добавлен, но удалённый GitHub Actions run не выполнялся. Репозиторий и публичный релиз не создавались автоматически. Поиск очевидных ключей/токенов в исходниках не является гарантией полного security/secret audit.
