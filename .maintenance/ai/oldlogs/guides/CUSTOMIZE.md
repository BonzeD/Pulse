# Pulse 1.9.2 — глобальная кастомизация (подготовка)

Статус: **фундамент готов, редактор и запуск пользовательского кода выключены** (`CZ_FLAGS` в `renderer/customize.js`).

## Что уже есть
- Вкладка **Настройки → Кастомизация**. Вверху — кнопка «Вернуть исходный вид».
- Модель `settings.layout` (в `DEF_SETTINGS`):
  ```js
  layout: { v: 1,
    items:   { <regionId>: { x, y, scale, hidden } },   // правки встроенных частей окна
    objects: [ { id, name, on, mount, html, css, js, x, y, scale } ] } // свои объекты
  ```
- Реестр частей окна `CZ_REGIONS` (верхняя панель, логотип, поиск, боковая панель, плеер внизу, обложка, текст…) — для каждой указано, что разрешено: `move / scale / hide`.
- Движок `czApply()`: всё применяется одним `<style id="czStyle">` (translate / scale / display:none). Инлайн-стили app.js не трогаются, откат мгновенный. Вызывается при любом `applyCustom()` (сброс, импорт, конфиги).
- Свои объекты: слой `#czLayer`, каждый объект в shadow DOM (его CSS не протекает в приложение). Поле `js` сохраняется, но **не выполняется**.
- Связь с конфигами: раздел «Кастомизация» (`layout`) добавлен в `CFG_PARTS` и в набор по умолчанию. Сброс перед очисткой сохраняет текущую раскладку конфигом «Резерв кастомизации · дата» — вернуть можно одной кнопкой в «Конфиги» или Alt+N.
- API для плагинов `Pulse.layout`: `regions() · register(id, {sel, name, group, move, scale, hide}) · get(id?) · set(id, patch) · clear(id) · addObject({...}) · removeObject(id) · reset()`.

## Что осталось сделать
1. **Редактор раскладки** (`CZ_FLAGS.editor`): режим поверх окна — клик выбирает регион из реестра, перетаскивание пишет `items[id].x/y`, колесо/ползунок — `scale`, кнопка «Скрыть». Логику перетаскивания, прилипания и отмены можно взять из редактора виджета (`editor.js`: `wHist`, `offLimits`, `clampV`).
2. **Добавление/удаление объектов**: каталог готовых блоков (часы, мини-визуал, кнопки действий) → `objects[]`.
3. **Объекты кодом** (`CZ_FLAGS.userCode`): редактор HTML/CSS/JS; JS — только в песочнице (`<iframe sandbox="allow-scripts">` + postMessage с узким API: плеер, трек, тема). Без доступа к `window.pulse`.
4. Регионы, которые меняют сетку (боковая панель, панель плеера) — через CSS-переменные `--side`, `--bar`, а не translate.
5. Миграции по `layout.v`.


## 1.9.3 — живой редактор окна включён
- `czEdit(page)` / `Ctrl+Shift+E` — режим редактирования (`body.cz-edit`), клики приложения перехватываются на `window` (capture).
- Выбранный элемент: если совпадает с объектом реестра — пишется в `items[<id>]`, иначе в `items[u<hash>] = { sel, n, x, y, scale, hidden, inl? }`,
  где `sel` строится `czSelector()` (ближайший предок с id + классы/nth-child). Элементы внутри `#page` получают префикс
  `body[data-czr="<маршрут>"]`, поэтому правка Главной не задевает другие страницы.
- Всё применяется одним `<style id="czStyle">` (`translate` / `scale` / `display:none`), в режиме редактора скрытое видно полупрозрачным.
- Ограничение: карточки на страницах выбираются по позиции (nth-child), поэтому при смене содержимого полки правка
  относится к той же позиции, а не к конкретному альбому.

## 2.0.10 — каркас «Панели»
- Регионы `CZ_REGIONS` и их селекторы не менялись; сохранённые раскладки работают в обоих каркасах.
- В «Панелях» `#side`, `#view`, `#pp` и `#bar` отстоят от краёв на `--ds-gap` (8 px) и скруглены `--ds-r3`. Ширины по-прежнему из `--side` и `--bar`.
- Если раскладка рассчитана на старый вид — «Настройки → Интерфейс → Вид окна → Классический».
