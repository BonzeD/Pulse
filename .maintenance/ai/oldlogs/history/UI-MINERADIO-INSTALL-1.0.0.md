# Pulse 1.0.0 — MineRadio: возврат панели и установка в выбранную папку

Версия приложения и имена файлов остаются 1.0.0. Предыдущие UI-исправления сохранены; текст песен, движок воспроизведения и 3D-рендерер MineRadio не менялись.

## MineRadio

- Воспроизведена ошибка реальным движением мыши внутри iframe: кнопка «Показать плеер» не появлялась.
- Сцена передавала координаты, но `PulseMR.wake()` игнорировал аргументы и создавал событие в точке (0, 0).
- Host теперь переводит координаты iframe в координаты окна с учётом положения и масштаба. Некорректные координаты и пустой вызов не создают ложного движения мыши.
- Удалён 120-мс пропуск pointermove в мосте: последнее движение в область возврата больше не теряется.
- Кнопка по-прежнему появляется только в нижней центральной области; анимация панели, клавиатурный возврат и отсутствие перехвата кликов вне кнопки сохранены.

## Установщик

- Проверка пути выделена в `build/install-path.nsh`: отдельные именованные переменные вместо общих `$1/$2`.
- Таймер анимации ранее менял общие регистры без сохранения. Теперь сохраняет/восстанавливает все 20 регистров; перед чтением пути таймер останавливается, включая переход с клавиатуры.
- Проверка формата/нормализации пути отделена от проверки возможности записи. Выделенные подпапки на C: и D:, пробелы и кириллица допустимы; корни дисков и основные личные/системные каталоги по-прежнему запрещены.
- Добавлена проверка создания каталога и записи в уникальный временный файл. Установщик не использует фиксированное имя для пробы и не перезаписывает существующий пользовательский файл.
- Для недоступной на запись папки предлагается согласованный перезапуск через UAC. Обычная установка остаётся без повышения прав. Перед перезапуском освобождается single-instance mutex; при отмене UAC блокировка восстанавливается и можно выбрать другой путь.
- Ошибка копирования больше не проходит как успешное завершение. Рекурсивное удаление выбранной папки не добавлялось.

## Ограничения проверки

Сборка и автоматизация выполняются на Linux. Реальные установка на D:, UAC, права Windows/антивирус и запуск Windows EXE в этой среде не проверены. Точная причина отказа на компьютере друга без нативного воспроизведения не подтверждена; обработка пути/таймеров исправлена и причины отказа записи теперь отделены от недопустимого пути.

При повторной ошибке нужны полный путь, точный текст нового сообщения и сведения о свободном месте/правах. Для Program Files обычно требуется согласиться на повышение прав; альтернатива — доступная пользовательская папка или portable.
