# Проверка исправлений плеера и локализации — 1.0.0

Номер версии закреплён автором: 1.0.0. Этот набор файлов заменяет предыдущую сборку с тем же номером; различать по SHA-256.

## Область изменений

1. `renderer/chrome.css`: прежние правила скрытия навигации в открытом Визуале распространены на Песню и Видео. Выход из плеера возвращает навигацию; Full/Clean, мини-предпочтения и fullscreen сохранены.
2. Удалены `renderer/cockpit.js`, `renderer/cockpit.css`, их подключения, настройки, команда и символ самолёта. Раздел «Остальное» оставляет декоративные настройки. Первые правила старого CSS относились к припевам: перенесены без изменений в `renderer/chorus.css`. Старый `settings.fun.cockpit` не используется и отбрасывается существующим mergeDeep по схеме без этого поля. Сам режим никогда не был отдельным сохранённым lib.mode; существующая загрузка дополнительно нормализует mode к cover/video/visual.
3. `renderer/i18n.js`: MutationObserver больше не откладывает walk через setTimeout. Перевод проходит на микрозадаче до paint, с объединением вложенных корней и пропуском удалённых узлов. Не используются скрытие интерфейса, непрозрачная маска или задержка кликов.
4. Переводы охватывают активный/неактивный аккаунт, действия и подсказки, Sync, раздельный префикс «Вошёл как», шаблон с произвольной моделью GPU и числовые счётчики офлайна. Имена аккаунтов и их инициалы защищены data-i18n-skip, даты используют текущую локаль.

## Проверки

- `npm test`: 83 теста, 0 ошибок. Исторические baseline-файлы не переписывались. Защитные проверки playback, GPU-алгоритмов и lyric timing сохранены. shell.js оставлен побайтно прежним, включая исторический комментарий.
- `tests/chrome-ui.cjs`: Full/Clean с perf-lite on/off; три режима; отсутствие зарезервированной колонки слева; восстановление навигации при закрытии; минимальная ширина окна 980; fullscreen; нет вкладки/команды/глобальных обработчиков Кабины даже при старом true/false флаге. Проверка 390 — только диагностическая геометрия, не обещание мобильной поддержки. Настоящий YouTube и аккаунты замоканы; Видео проверено в интерфейсе с аудио-fallback, сетевой видеопоток не проверялся.
- `tests/locale-flash-ui.cjs`: 20 синтетических кадров воспроизводили исходный русский текст до исправления; после исправления все 20 локализованы до rendering opportunity. Дополнительно 45 последовательных кликов по реальным обработчикам разделов app/accounts/sync для каждого из en/ja: нет русского UI-текста или подсказок в контрольной точке перед paint. Имена аккаунтов специально русские («Настройки», «Главная») и остаются неизменными. Тот же контракт проверен в подключённом same-origin документе. Возврат на русский проверен.
- `tests/locale-sweep.cjs`: существующий обзор настроек, редактора и экранов en/ja; успешен. Этот обзор использует явный walk и сам по себе не доказывает отсутствие мигания — для этого предназначен отдельный покадровый тест выше.
- `tests/motion-ui.cjs`: проверка сохранности переходов, быстрых повторных открытий, Full/Clean, уменьшенного движения и отключения анимаций.
- Визуально просмотрены отдельные live-снимки Песня/Видео Full/Clean при 1366 и 980; и accounts/sync/GPU в en/ja. Русские имена в фикстурах — намеренно пользовательские данные, не пропущенные UI-переводы. В fallback-видео может отображаться штатный временный toast о недоступности встраивания.

## Ограничения

Linux Chromium и проверки упаковки не заменяют запуск приложения и установщика на Windows. Реальная установка, медиаклавиши на Windows, сетевое видео и входы в аккаунты здесь не проверены. EXE не подписаны.
