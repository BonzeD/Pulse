# Pulse 1.0.0 — проектный Spicy Lyrics и завершение пресета

## Spicy Lyrics

По прямому разрешению автора его проектный ключ включён в `spicy-project.js` основного процесса. Этот модуль включён в Windows-сборки и исходный архив. Ключ не передаётся в renderer, IPC-ответы, пользовательский профиль или экспорт настроек. Это не защита от извлечения: содержимое Electron-приложения и исходников доступно владельцу файлов.

- Удалены поле «Ключ Spicy Lyrics API», проверка пользовательского ключа и подсказки ввести его в настройках.
- Обычный плеер и полноэкранный Spicy-вид используют проектное подключение без ввода ключа пользователем.
- Выбор Spicy как источника работает независимо от старого поля персонального ключа. В режиме «Все источники» сохранён переключатель обращения к Spicy. Оформление и атрибуция авторов текстов сохранены.
- Запрос выполняется только к официальному HTTPS endpoint, Spotify ID проверяется, редиректы запрещены; прежние таймаут, кеширование и резервные источники остаются.
- Старое поле `settings.spicy.key` сохраняется лишь для совместимости профилей, больше не участвует в авторизации. Проектный ключ не находится в этом поле.
- При UI-проверке обнаружен и исправлен прежний сбой статических текстов без массива `words`.

Контрольный запрос к официальному API с проектным подключением: HTTP 200, распознанный payload текста. Это проверка одного запроса, не гарантия доступности всех песен или будущих лимитов сервиса.

Публикация проекта на GitHub не выполнялась. Условие публикации, указанное автором ключа, этим архивом не считается выполненным.

## Остальная работа

Основной авторский пресет завершён: см. `PRIMARY-PRESET-1.0.0.md`. Значения точно совпадают с предоставленным файлом. Новый профиль получает их сразу; существующий — через подтверждаемую кнопку «Основной пресет» внизу «Основные». Библиотека, аккаунты и скачанные файлы не удаляются.

Сохранены импорт локальных треков в отдельный плейлист, редактор метаданных/обложек локальных и скачанных треков, восстановление оригинала и экспорт в несколько форматов. Сохранены исправления полного Python runtime загрузчика, копирования ссылок и обработки путей установщика. Подробности — исторические `LOCAL-MEDIA-1.0.0.md` и `DOWNLOAD-PRESET-1.0.0.md`.

## Проверки текущего кода

- 138/138 Node-тестов; исторический baseline не переписан. Точные изменения Spicy проверяются отдельным списком разрешённых замен относительно оригинала.
- 8 UI-сценариев основного пресета, 5 сценариев ссылок/экспорта настроек, 10 сценариев локальных треков/метаданных.
- Spicy UI: удалённые элементы действительно отсутствуют; полноэкранный запрос не получает ключ аргументом; текст без таймингов отображается без исключения. Скриншоты интерфейса проверены отдельно.
- Реальная установка/UAC и нативный clipboard на Windows в Linux-среде не проверялись. Требуется контроль на Windows; браузерный стенд не заменяет его.

Версия остаётся 1.0.0; для различения пересборок используются контрольные суммы.
