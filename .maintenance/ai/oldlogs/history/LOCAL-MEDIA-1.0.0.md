# Pulse 1.0.0 — локальная музыка и метаданные

## Как пользоваться

1. Открой «Локальные треки» в списке плейлистов и нажми «Добавить треки».
2. Выбери один или несколько аудиофайлов. Pulse создаст свои копии; исходные файлы останутся на месте.
3. В строке локального трека нажми карандаш или открой «Ещё → Редактировать метаданные…». В Clean — через «Ещё».
4. Для скачанного трека редактор открывается из того же меню «Ещё».
5. «Применить» сохраняет свою версию тегов и обложки в Pulse. Аудиоданные не перезаписываются.
6. «Восстановить оригинал» возвращает первоначальные поля и обложку.
7. Выбери формат и нажми «Сохранить файл…», чтобы экспортировать текущие поля редактора в отдельный файл. Необязательно сначала применять их в библиотеке. Отмена экспорта сохраняет черновик в открытом редакторе.

## Возможности

- Отдельный системный плейлист «Локальные треки»: не смешивается со «Скачанным», работает без аккаунта и интернета.
- Импорт: MP3, FLAC, WAV, M4A, AAC, OGG, OPUS, WebM, AIFF/AIF, WMA, ALAC, M4B, MP4 с аудио, APE, WavPack/WV, MKA. Корректность файла проверяется медиапроцессором, не только расширением.
- Проверены на настоящих тестовых файлах: MP3, FLAC, WAV, M4A/AAC, AAC, OGG/Vorbis, OPUS, WebM/Opus, AIFF, WMA, M4B/ALAC. Остальные поддерживаются при наличии распознаваемого аудиопотока/кодека; DRM не поддерживается.
- Для форматов/кодеков вне нативного браузерного тракта создаётся отдельная FLAC-копия для воспроизведения. Импортированный оригинал сохраняется отдельно.
- Дубли идентифицируются по SHA-256 содержимого файла. Разные кодировки/форматы одного произведения считаются разными файлами.
- Поля: название, исполнитель, альбом, исполнитель альбома, год, жанр, номер трека, номер диска, композитор, комментарий.
- Обложки: встроенные из тегов либо JPG/JPEG, PNG, WebP до 20 МБ. Новые обложки нормализуются в JPEG, без изменения исходной картинки.
- Экспорт: MP3, FLAC, M4A (AAC/ALAC), OGG/Vorbis, OPUS, WAV. Если кодек совпадает с выбранным форматом — аудио копируется без перекодирования. При смене формата используются штатные кодеки FFmpeg; FLAC/WAV не восстанавливают качество, уже утраченное в исходном сжатом файле.
- Обложка встраивается при экспорте. В WAV добавляется ID3v2.3 с UTF-16 и обложкой, плюс отдельный JPG для совместимости с проигрывателями, игнорирующими ID3 в WAV. WAV-экспорт ограничен 4 ГБ; для больших файлов предложен FLAC.
- Экспорт запрещён поверх зарегистрированных исходных файлов и в служебные каталоги; проверяются также символьные ссылки. Незавершённый экспорт не заменяет старый файл.
- Локальные треки можно добавлять в обычные плейлисты Pulse. Выгрузка таких файлов в YouTube Music не имитируется и блокируется.

## Хранение

- `%APPDATA%/Pulse/local-media` (фактическое имя userData задаётся Electron): неизменяемые копии аудио, адаптированные копии воспроизведения, исходные/редактированные обложки.
- `media-library.json` с резервной копией: оригинальные метаданные, пользовательские изменения и список локальных треков.
- Сброс только настроек не удаляет медиатеку. При полном сбросе с сохранением скачанной музыки сохраняются также локальные треки и метаданные. Полный сброс без сохранения удаляет библиотеку Pulse, не внешние исходные файлы.
- Импорт/экспорт/обложка используют нативные диалоги ОС. Renderer не передаёт произвольные пути чтения файлов. IPC защищён существующей проверкой основного окна и origin.

## Установщик

Предыдущая проверка использовала opcode NSIS `GetFullPathName`. В используемой ветке NSIS он дополнительно проверяет существование последнего компонента пути и может очищать результат, если новая папка ещё не создана. Это объясняет отказ для обычного нового `C:\Program Files\Pulse`/`D:\Apps\Pulse`, который повышение прав не устраняет.

В `build/install-path.nsh` используется напрямую Windows `GetFullPathNameW`, не требующий существующей конечной папки. Проверка длины, корней дисков и личных/системных папок сохранена; затем отдельно проверяются создание каталога и запись. Для Program Files при необходимости предлагается UAC. Защитный mutex корректно передаётся при перезапуске.

Размер на графике установщика пересчитывается по собранному приложению; графика обновляется при изменении размера или исходного дизайна. Надпись о правах уточнена: они зависят от выбранной папки.

## Проверки и ограничения

- `npm test`: 123/123, включая тесты действительных аудиофайлов, round-trip тегов и обложек, восстановления, безопасного экспорта, побайтовой неизменности исходников и совпадения декодированного PCM при FLAC→FLAC.
- `tests/local-library-ui.cjs`: 10 сценариев, реальный backend/FFmpeg и локальный HTTP-аудиотракт, UI Full/Clean, ширина 390 px, сохранение/сброс/черновой экспорт, повторный запуск и обновление метаданных при новом выборе сетевого трека.
- Сохранены и повторно проверены прежние исправления: MineRadio-панель, затухание/анимации, настройки, вода/отражение, прочий UI, motion/audio regression suites.
- `npm audit --omit=dev`: 0 известных уязвимостей в npm production-зависимостях на момент сборки. Это не аудит сторонних EXE и не гарантия отсутствия неизвестных проблем.
- Номер версии остаётся 1.0.0, сборки различаются контрольными суммами.

Проверки выполняются на Linux с Chromium и FFmpeg. Системные файловые диалоги в UI-автоматизации заменены управляемыми ответами; их интеграция проверена по коду. Нативный запуск Windows EXE, установка на физический D: и прохождение UAC в этой среде не выполнялись. Финальную проверку новой установки следует повторить на Windows, особенно на компьютере, где воспроизводилась ошибка.

Лицензии/происхождение FFmpeg и FFprobe — `resources/media-tools`, уведомления — `NOTICE.md` и раздел «О приложении». Парсер метаданных — music-metadata 11.16.1 (MIT).
