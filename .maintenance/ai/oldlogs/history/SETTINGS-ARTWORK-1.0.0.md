# Pulse 1.0.0 — настройки и обложки Apple Music

Кандидат **settings-artwork** поверх kinetic-motion. Версия **1.0.0**; на GitHub не опубликовано.

## Переключение настроек

На приложенном видео выборочно просмотрены кадры 0,5 / 2,5 / 4,5 / 7,5 секунды. В одном из кадров правая панель пуста после выбора «Аккаунты».

- Старое содержимое остаётся на месте во время короткого выхода (90 мс), затем новое плавно появляется за 260 мс с небольшим смещением. Прозрачность перехода не опускается до нуля. Удалено принудительное измерение offsetWidth при каждом выборе раздела.
- Живые превью не клонируются: используется существующий keepAliveRender. Во время выхода старые контролы inert, затем снова доступны. Фокус выбранного пункта восстанавливается после замены навигации.
- Повторный рендер данных в том же разделе не запускает анимацию заново. При быстром переключении применяется последний раздел, без очереди старых переходов. Прокрутка внутри текущего раздела сохраняется.
- Поддерживаются Full/Clean, узкие окна, настройка «Без анимаций» и живое системное reduced-motion.
- Новый модуль событийный: нет постоянного RAF, анимированного blur, снимков всей страницы или дополнительных фоновых Worker.

## Личные обложки плейлистов Apple Music

- Общий список запрашивает связь catalog; приоритет у artwork самого библиотечного плейлиста, затем у его каталожного соответствия. Для личного плейлиста обложка первого трека больше не выдаётся за пользовательскую картинку.
- Для отсутствующей/ошибочной картинки карточка запрашивает только метаданные конкретного плейлиста через отдельный IPC, без загрузки всех его треков.
- Artwork URL корректно разворачивает все вхождения шаблонов размера и формата, сохраняет подписанные query-параметры без повторного кодирования. Допускаются только HTTPS-адреса CDN mzstatic.com; ID плейлистов проверяется до запроса.
- В очереди не больше двух запросов метаданных; одинаковые запросы объединяются. Успешная картинка кэшируется только после загрузки изображения, отражается в карточке и сохранённом списке библиотеки. Ошибка не отравляет успешный кэш; действует пауза повторов. Ушедший со страницы элемент не изменяется поздним ответом.

**Ограничение:** реальный аккаунт автора в среде не подключён. Проверены фикстуры Apple metadata и загрузка изображений в браузере; это не подтверждение ответа API для ANŒTHR WØRLD, Myme или Recommended. Если Apple не возвращает artwork ни в деталях библиотеки, ни в catalog, приложение не может восстановить отсутствующую картинку из этих данных. После установки открыть Apple Music → Библиотека, подождать обновления списка и проверить собственные обложки. Пароли/токены в чат не присылать.

## Границы

Относительно kinetic-motion побайтно сохранены Viz, GPU, lyStage (включая оптимизацию кинетики), движок MineRadio и installer.nsi. В app.js меняется только панель настроек; фон и рендер не тронуты. Worker из fix2 не возвращён. Не снижались FPS, качество, плотность частиц и эффекты. Исправление установщика без запуска старого Pulse.exe сохранено. Проверка: docs/settings-art-checks/scope.json и app-settings.diff.

Предыдущие отчёты и контрольные суммы остаются историей. Проверки защиты текущего кандидата не являются независимым пентестом.

## Проверки

- 258/258 unit/regression, включая 8 новых контрактов Apple artwork и переходов.
- 46 проверок settings-art UI: сохранение старой панели, промежуточный кадр, быстрые переключения, рендер того же раздела, прокрутка, reduced-motion, Full/Clean на 1366/390 px; пять обложек, максимум два запроса, сохранение, повторный рендер, пустой ответ, ошибка изображения, дедупликация и уход со страницы.
- PNG промежуточного кадра, четырёх Full/Clean-размеров и карточек с тестовыми картинками просмотрены по одному. Подмена картинок логотипом Pulse используется только в тесте, не в приложении.

Это локальный headless Chromium с заглушками сервисов. Реальные FPS, нативные drag-зоны, SMTC/Island и установка поверх работающего Pulse требуют Windows. Сборки не подписаны; не отключать защиту Windows.

- Повторно пройдены 280/280 FX, 50 проверок кинетики/переходов, 70 проверок виджета, общий UI, файловое видео/меню, motion-ui и splash.

## Комплект поставки

В ASAR побайтно совпадают 190 файлов проекта. Из Setup и portable извлечено по 226 файлов runtime, точное совпадение с win-unpacked. Дополнительные файлы самого установщика (NSIS plugins/UI и uninstaller) проверены отдельно от runtime. Версия пакета 1.0.0. Исходники не содержат node_modules, dist, нативных bin/obj или пользовательских данных. Исторические манифесты сохранены; SOURCE-MANIFEST-settings-artwork.txt описывает текущий исходный архив. Три ZIP проверены на целостность; SHA256SUMS-settings-artwork.txt содержит суммы этих ZIP. Это не прогон установки на Windows.
