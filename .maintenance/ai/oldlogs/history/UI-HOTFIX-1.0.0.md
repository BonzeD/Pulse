# Pulse 1.0.0 — исправления после проверки интерфейса

Версия остаётся **1.0.0**. Этот отчёт уточняет текущий результат; UI-FIXES-1.0.0.md сохранён как история предыдущей пересборки.

## Исправлено

- Убрана именно кнопка выбора платформы текста «Все источники» из панели визуализатора. Кнопка эффектов визуала возвращена вместе с обработчиком. Выбор источника в настройках и у подписи текста сохранён.
- Расширение холста больше не меняет музыкальную сцену: размеры и центры пресетов рассчитываются по сцене, а Canvas 2D имеет отдельный запас сверху/снизу. Координаты обложки переводятся в ту же систему. WebGL direct имеет собственный stage-sized framebuffer. Постоянное мягкое затухание справа сохранено, настройка «Края визуала» не возвращена.
- Изменения раскладки обычного текста, свечения и отражения **текста** из прошлой пересборки откатили. karaoke.js, kara.css, spicy.js, spicy.css, lystage.js, refl.css и style.css совпадают с присланным исходным архивом побайтно. Исправления самого окна корректора и возможность изменения ширины правой панели сохранены.
- Воспроизведён отказ открытия настроек при неполном профиле аккаунта: appPreview вызывал account.name.split без проверки. Предпросмотр теперь допускает отсутствующее имя, некорректный список полок и не может сорвать построение всех настроек. Ошибки синхронного построения страниц больше не оставляют молча подсвеченный пункт поверх старой страницы. Это воспроизведённый сценарий с тем же симптомом; точное содержимое профиля и плагинов пользователя недоступно.
- Водная гладь обложки: усилено видимое волновое движение, добавлено вертикальное преломление изображения. Нулевое смещение у водной границы, ширина и скругления обложки сохранены. Simple, нулевая рябь и системное уменьшение движения оставляют отражение неподвижным.
- Для лишней точки: скрытое в пресетах без обложки дерево artwork/iframe больше не рисуется и не принимает клики; расширенный холст очищается целиком, скрытый WebGL-слой явно исключается из отрисовки при смене пресета. Точная точка с присланного небольшого фрагмента отдельно не воспроизведена; её устранение на компьютере пользователя не подтверждено. Если останется, нужен полный кадр с названием пресета и положением курсора.
- У фокуса разделителя панели подсвечивается ручка, а не вся высота границы.

## Проверки

- `npm test`: **95 / 95**.
- `CHROMIUM_PATH=/usr/local/bin/chromium npm run test:ui-fixes`: **17 сценариев**, без ошибок JavaScript.
- `CHROMIUM_PATH=/usr/local/bin/chromium npm run test:hotfix`: **4 расширенных сценария** — все встроенные пресеты на 980/1444/1918 px, центры обоих direct GPU-пресетов и скрытие GPU при переключении, настоящие клики настроек/вкладок/создания плейлиста после перебора визуалов, изменение пикселей воды именно в живом цикле.
- Реальные mouse-click проверки отдельно покрывают настройки при неполном профиле, переходы между страницами, переключатель режима настроек, кнопку эффектов, скрытие и возврат плеера. Не подменяются вызовом go().
- `tests/motion-ui.cjs`: прерывания анимаций, повторное открытие, Full/Clean, 390/980/1366 px, reduced motion и отключённые анимации — пройдено.
- `tests/audio-signal.cjs`: реальный синусоидальный сигнал через локальный тракт/iframe в визуализатор, бас и MineRadio — пройдено.
- Проверены разные пиксели водного отражения в normal/ultra/glitch, неподвижность simple, движение в живом цикле и остановка при reduced motion.

## Сборка и ограничения

`DOTNET=/data/dotnet/dotnet npm run dist` создаёт Windows x64 portable и установщик с медиамостом. Проверяется формат обоих EXE и совпадение упакованных исходников с этой рабочей копией.

Проверки выполнены на Linux/Chromium с имитацией IPC и тестовыми данными. Запуск и установка на реальном Windows, авторизация сервисов и точное состояние пользовательского профиля здесь не проверяются. Бинарники без цифровой подписи, как и исходная конфигурация сборки. Движки аудио и сетевые сервисы не переписывались.
