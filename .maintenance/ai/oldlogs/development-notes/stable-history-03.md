# Pulse 1.9.6

- Караоке: слова теперь подсвечиваются вовремя — whisper считает время каждого слова через DTW (`-dtw`), средняя ошибка ~0.7 с → ~0.13 с. Уже синхронизированные треки один раз пересинхронизируются сами.
- Текст больше не «каша»: убрано свечение, просвечивающее сквозь незаполненные буквы; увеличение слова больше не съедает пробелы.
- Эффекты: убраны блюр/тряска невыпетых слов, мягче «прыжки», удар и сглаживание баса не зависят от FPS — эффекты ровнее идут в темп.
- Меню «Стиль визуализации» и панели эффектов не залезают под заголовок окна — «Кольцо» снова нажимается в маленьком окне.
- Настройки → «Сбросить все настройки» (реально сбрасывает, с перезапуском) и «Удалить все данные» (настройки, библиотека, аккаунт, кэш; скачанные треки — по выбору).
- Деинсталлятор по умолчанию удаляет настройки и данные (%APPDATA%\Pulse); скачанные треки — отдельной галочкой.

## Аккаунт
- «Аккаунт Google» без имени (битые/неполные cookies) больше не появляется: такой вход не считается входом, cookies чистятся, запись удаляется из списка автоматически.
- Импорт входа из браузера больше не смешивает старые и новые cookies; если новый вход не удался — возвращается прежний аккаунт.
- «Войти через Google» открывает обычный браузер (Edge/Chrome/Firefox/Brave/Яндекс) без отладочного порта — Google не пишет «браузер небезопасен». Войди → закрой окно → Pulse забирает вход.
- Убраны «Файл cookies.txt» и «Вставить Cookie вручную». «Взять готовый вход из браузера» пока оставлен.
