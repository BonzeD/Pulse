# Pulse 2.0.1

## Интерфейс
- Убран значок «онлайн» рядом с логотипом. Плашка появляется только когда пропал интернет («офлайн»).

## Страница исполнителя
- Кнопка «Подписаться» / «Вы подписаны» — подписка на исполнителя в YouTube Music (нужен вход в аккаунт).
- Под именем показываются «слушателей в месяц», если YouTube Music их показывает (например, «289 тыс. подписчиков • 1,71 млн слушателей в месяц»).

## Текст песен — переписан с нуля
- Новый модуль источников `lyrics.js`. Три базы опрашиваются параллельно, выбирается лучший вариант:
  - **Musixmatch** — пословная синхронизация (каждое слово со временем начала и конца), строки, обычный текст;
  - **NetEase** — пословная синхронизация (YRC) и строки;
  - **LRCLIB** — строки и обычный текст.
- Совпадение проверяется по исполнителю, названию (в том числе латиница ↔ кириллица: «Korol i Shut» = «Король и Шут»)
  и длительности. Для slowed / sped up подбирается темп.
- Пословная синхронизация хранится в обычном LRC с тегами `<мм:сс.сс>` — работает с корректором, офлайн и в виджете.
  У слова есть время конца, поэтому караоке-заливка идёт ровно по длине слова.
- Если в базе есть только время строк — слова раскладываются по слогам в реальную длину строки и притягиваются к атакам голоса.
  Знаки «—», «…» больше не загораются отдельным «словом».
- Разбор LRC: повторы тегов строки, `[offset:]`, пустые строки как паузы.
- Загрузка защищена от «опозданий»: ответ для прошлого трека больше не перерисовывает текущий.
- Старые сохранённые тексты один раз перепроверяются — у многих треков появится пословная синхронизация.
  Своя синхронизация и вручную выбранные тексты не трогаются.
- Ручной поиск в корректоре ищет во всех трёх базах и показывает «по словам» / «по строкам».

## Нейросеть
- Вместо старой встроенной модели base — **Whisper large-v3-turbo** (точная, хорошо понимает русский, рэп и пение под битом).
  Скачивается один раз в Настройки → Текст песен (574 МБ). Есть лёгкая модель small (190 МБ) для слабых ПК.
- Старая модель base удалена из установщика — он стал меньше.
- Нейросеть больше не переписывает автоматически тексты, у которых уже есть время из базы (раньше она часто портила
  хорошие тайминги). Автоматически — только для обычного текста без времени и когда текста нет совсем.
  Для остальных — кнопка «По голосу» в корректоре.
