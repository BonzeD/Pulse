# Pulse 1.0.0 — исправления локализации

## Состав

- Исправлены переводы собственных подписей интерфейса: карточки медиатеки, счётчики загрузок, редактор, placeholder Custom CSS, статус Discord RPC и раздел About.
- Проверяются русский (исходный язык), английский, японский и украинский. Названия пользовательского контента не переводятся.
- Устранён конфликт имени функции перевода с таймером автоскрытия UI, обнаруженный при полной проверке перед сборкой.
- Проверка исходной версии не требует gitignored-графики установщика в чистом клоне; отдельный тест проверяет её после генерации.
- Сохранены версия 1.0.0, прежний установщик, исправления кнопок и запрет запуска старого EXE во время установки/удаления. Качество и лимит FPS не снижались.

## Подготовка для GitHub

1. Распаковать `Pulse-1.0.0-source.zip` и загрузить **содержимое** папки `Pulse-1.0.0` в репозиторий, включая `.github` и `.gitignore`.
2. Предпочтительно использовать Git / GitHub Desktop: включённые ffmpeg.exe и ffprobe.exe превышают лимит одного файла веб-загрузчика GitHub (25 МиБ). Каждый из них меньше 100 МиБ.
3. Не добавлять `node_modules`, `dist`, локальные `.env`, пользовательские профили и токены. Исходный ZIP не содержит зависимостей npm и выходных файлов сборки.
4. В Actions выбрать **Build Windows artifacts → Run workflow**. Workflow также запускается при push тега вида `v*`; он собирает артефакт, но **не публикует Release автоматически**.
5. В GitHub Releases создать выпуск `v1.0.0` и прикрепить `Pulse-Setup-1.0.0.exe`, `Pulse-1.0.0-portable.exe` и SHA256SUMS.txt из Windows-архива. Если тег уже существует, не перезаписывать его вслепую: эту пересборку различать описанием и SHA-256.

## Сборка на Linux (как в GitHub Actions)

Нужны Node.js 24, .NET SDK 8, Python 3 + Pillow, Chromium и системные библиотеки Chromium.

```sh
npm ci
npm test
npx playwright install --with-deps chromium
python3 -m pip install Pillow
export CHROMIUM="$(node -e "console.log(require('playwright').chromium.executablePath())")"
npm run dist
# После сборки проверяется также сгенерированная графика установщика:
npm test
```

Выходные файлы находятся в `dist/`. Прямой `npm run dist` использует shell-скрипты и linux-makensis; приведённые команды предназначены для Linux/WSL/GitHub Actions, не для PowerShell.

## Границы проверки

Windows-артефакты кросс-собраны на Linux. Проверки UI выполняются в Chromium и не заменяют реальный Windows-прогон. Перед публичным выпуском проверить установку/обновление играющего Pulse, удаление, SMTC, кнопки виджета, вход в сервисы и FPS на целевом Windows-ПК. Регрессия FPS на Windows не считается доказанно устранённой.

Установщик и portable не подписаны сертификатом: возможны предупреждения Windows SmartScreen.

## Ключи и зависимости

По ранее зафиксированному разрешению автора проектный ключ Spicy Lyrics сохранён в `spicy-project.js`. Он извлекается из исходников и Electron-сборки, то есть после публикации не является секретом. Разрешение и ограничения описаны в `SPICY-PROJECT-1.0.0.md`. Не подставлять вместо него личные приватные ключи. При необходимости секретного доступа нужен серверный прокси, а не упаковка ключа внутрь EXE.

При `npm ci` npm сообщил о 8 уязвимостях умеренного уровня. Автоматическое обновление зависимостей с потенциальными несовместимыми изменениями в эту пересборку не включено; полный аудит безопасности не заявляется.
